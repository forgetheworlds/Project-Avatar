|---|---|---|

| **Form Factor** | Single-board AIO (FC + 45A 4-in-1 ESC) | Stack component (requires separate ESC) |

| **IMU (Gyro/Accel)** | Dual: BMI088 + BMI270 | Single: ICM42688P |

### UART Pinout Comparison for Splash Wiring

| Peripheral | MicoAir H743 v2 | SpeedyBee F405 Mini |
|---|---|---|
| **GPS** | UART3 (TX3/RX3) | UART3 (TX3/RX3) |
| **Compass (I2C)** | SDA/SCL (external) | SDA/SCL (external) |
| **ELRS/CRSF RX** | UART6 (TX6/RX6) | UART2 (TX2/RX2) |

### Verdict for Splash

**MicoAir H743 V2 AIO 45A is the definitive choice.** Reasons:
1. **13-15g saved** vs SpeedyBee stack — critical for sub-250g margin
2. **H7 processor** handles ArduPilot EKF3 + logging + autonomy without strain (F405 struggles)
3. **Dual IMU** (BMI088 + BMI270) provides sensor redundancy — important for autonomous mode safety
4. **MicroSD blackbox** enables unlimited logging for PID tuning
5. **11mm stack height** on Master3X only fits AIO boards — MicoAir fits perfectly
6. **Built-in 45A ESC** with 219% headroom over 1505 motor peak draw

**Existing fact F-2026-05-28-001 CONFIRMED** — v2 (45A) is active, no built-in compass requires external GPS compass.

### Flight Time Estimates

| Scenario | Current Draw | Usable Capacity (80%) | Flight Time |
|---|---|---|---|
| **Hover (payload idle)** | 5.82A | 0.68 Ah (850mAh × 80%) | **~7.0 min** |
| **Hover + pump active** | 5.96A | 0.68 Ah | **~6.8 min** |
| **Aggressive flight (50% throttle avg)** | ~11.0A | 0.68 Ah | **~3.7 min** |
| **Freestyle/punchy** | ~15.0A | 0.68 Ah | **~2.7 min** |
| **Protection mode (orbit + intermittent fire)** | ~7.5A | 0.68 Ah | **~5.4 min** |

### Key Insight: Protection Mode Budget

- Prior research (F-2026-05-29-006) estimated ~2.5-2.8 min protection mode on 4S 850mAh with 5 burst fires
- This revised analysis with actual component draws shows **~5.4 min of orbit + intermittent fire**
- **Discrepancy:** Earlier estimate used 13.3A hover draw (too high for 1505 motors at hover — that's 60% throttle). Actual hover for 1505 3800KV at ~260g AUW is ~5.5A total (about 15-20% throttle based on 8:1 TWR)
- **Result: Protection mode endurance is ~5 min, not 2.5 min** — significantly better than previously thought

### Critical: External BEC Required

- MicoAir H743 onboard 5V rail is **2A total** — cannot power ESP32 (~350mA peak) + camera (~200mA) + ELRS (~30mA) + servo (~500mA stall) + pump relay simultaneously
- **Action: External 5V/3A BEC** required for servo + ESP32. Wire directly to LiPo pads.
- Add **470µF low-ESR capacitor** across power leads to filter motor noise

## §4. 🟢 NEW: Hawkeye Thumb 4K — Complete Integration Guide

**Source:** Google AI Mode (18 sources, Oscar Liang, FirstQuadcopter)

### Weights & Versions

| Version | Weight | Internal Battery? | Recommendation |
|---|---|---|---|
| Hawkeye Thumb 4K (Naked) | **15.5-16g** | No — powered externally | ✅ **Splash choice** |
| Hawkeye Thumb 2/3 | 34.5-35g | Yes | ❌ Too heavy for sub-250g |

### Mount Design Options

1. **Integrated Hard Mount**: GoPro-style molded bracket with M3 holes — bolt directly to TPU camera plate, no extra 3D-printed weight
2. **3D Printed TPU Mount**: Minimalist couch mount, 15-25° angle, TPU 95A shore hardness to prevent low-frequency resonance
3. **ND Filter Clearance**: Leave space for slip-on ND16/ND32 filters (control shutter speed, reduce jello)

### Power Wiring

```
[Hawkeye Back Port]                [Flight Controller]
  Pin 1: DC Power (5-23V)  ---->  VBAT (Direct Battery) or 5V/9V BEC Pad
  Pin 2: Ground (GND)      ---->  GND Pad
  Pin 3: Video Out          ---->  CAM / Video In Pad (Optional for Analog FPV)
  Pin 4: RX/Remote Click    ---->  Free UART TX Pad (Optional Control)
```

**Critical wiring notes:**
- Internal regulator handles **DC 5-23V** — can wire to VBAT directly (up to 5S)
- Add **470µF low-ESR capacitor** to main battery leads for noise filtering (motor braking spikes)
- Do NOT power from FC 5V rail if servo/pump also on it — risk of brownout
- Video-out is PAL/NTSC analog (~40ms latency) — usable for framing, not primary flight feed

### Gyroflow Stabilization Settings

**Resolution selection (CRITICAL):**
- ✅ **4K @ 30FPS** — works, gyro logging enabled
- ✅ **2.5K 4:3 @ 50FPS** — best quality, gyro logging enabled
- ❌ **4K @ 50FPS** — **MAXES OUT PROCESSOR, DISABLES GYRO LOGGING**

**Gyroflow parameters:**
- Lens Profile: Select "Hawkeye Thumb 4K" matching resolution/aspect ratio
- Sync: Run Auto Sync (trim shaky start/end if needed)
- Stabilization: **Velocity Dampened** or **Plain 3D** for cinematic cruising
- Smoothness: **0.20-0.25** (stock 0.04 over-corrects → excessive crop)

### Vibration Dampening
- Soft mount silicone/rubber bobbins between mount base and frame top plate
- Dynamic propeller balancing — damaged props destroy footage
- Enable RPM Filtering in Betaflight (Splash runs ArduPilot — use harmonic notch filter INS_HNOTCH_ENABLE=1 per F-2026-06-03-058)

## §5. 🟢 NEW: ESP32-S3 DroneBridge — Complete Specs & Wiring

**Source:** Google AI Mode (36 sources, DroneBridge GitHub, ArduPilot docs)

### Performance Specifications

| Metric | Standard WiFi Mode | ESP-NOW / WiFi LR Mode |
|---|---|---|
| **Max Range** | 150m+ (depends on GCS antenna) | **1km+** (line-of-sight, dual ESP32) |
| **Data Rate** | Up to 11 Mbps | ~250 kbps |
| **Air Latency** | 5-15ms | **2-8ms** |
| **Encryption** | WPA2 / AES-GCM 256-bit | Custom AES-GCM 256-bit |
| **Average Current (5V)** | ~110 mA | ~180-240 mA (continuous Tx) |
| **Peak Current (5V)** | ~350 mA | ~450 mA (RF spikes) |
| **Weight (module only)** | <2g | <2g |

### Wiring Diagram

```
+------------------------+        +------------------------+
|   ArduPilot FC UART4   |        |   ESP32-S3 Module      |
|                        |        |                        |
|   5V (>=500mA BEC)    | -----> |   VIN/5V               |
|   GND                  | -----> |   GND                  |
|   TX4                  | -----> |   RX (GPIO18)          |
|   RX4                  | -----> |   TX (GPIO17)          |
+------------------------+        +------------------------+
```

### ArduPilot Parameters

| Parameter | Value | Description |
|---|---|---|
| `SERIAL4_PROTOCOL` | 2 | MAVLink 2 |
| `SERIAL4_BAUD` | 115 | 115200 baud (or 576 for ESP-NOW LR) |

### Setup Steps
1. **Flash firmware**: Connect ESP32-S3 via USB-C, open DroneBridge Web Flasher at drone-bridge.com, select target firmware
2. **Configuration**: Power drone, connect to "DroneBridge ESP32" WiFi (password: `dronebridge`), navigate to `http://192.168.4.1`
3. **Mode selection**: Choose WiFi AP (150m range) or ESP-NOW LR (1km+ range, needs ground ESP32)
4. **Antenna**: IPEX connector + 2.4GHz dipole antenna (1-2g) required for 1km range

### Confirmed with Existing Facts
- F-2026-06-03-053 (DroneBridge updates) ✅ **confirmed and expanded** with 2026 feature list
- F-2026-06-03-064 (DroneBridge wiring) ✅ **confirmed** — ESP32 on UART4, SERIAL4_PROTOCOL=2
- F-2026-06-03-056 (IPEX antenna) ✅ **confirmed** — ceramic antenna limited to 150m, IPEX needed for 1km
