## 1. FLIGHT CONTROLLER: MicoAir H743 AIO vs Alternatives

### MicoAir743-AIO-35A (original - discontinued)
- **MCU:** STM32H743 (Cortex-M7, 480MHz)
- **IMUs:** Dual BMI088/BMI270
- **Baro:** DPS310
- **ESC:** Integrated 4-in-1 AM32 35A
- **BEC:** 12V@2A + 5V@2A
- **Size:** 36×36×8mm, 25.5×25.5mm mount
- **Weight:** ~10g
- **UARTs:** 7 (SERIAL0-USB, SERIAL1-UART1 MAVLink DMA, SERIAL2-UART2 DisplayPort, SERIAL3-UART3 GPS DMA, SERIAL4-UART4 MAVLink, SERIAL5-UART6 RCIN DMA, SERIAL6-UART7 ESC Telemetry RX-only, SERIAL7-UART8 User DMA)
- **Firmware:** ArduPilot, PX4, Betaflight, INAV
- **Price:** $64.99 (discontinued, still available)

### MicoAir743v2-AIO-45A (current version — RECOMMENDED)
- **ESC:** 45A AM32 (vs 35A on v1) — better headroom for payload
- **Weight:** ~10g (same)
- **Price:** $69.99
- **Mount:** 25.5×25.5mm
- **Full ArduPilot support**

### SpeedyBee F405 Mini (alternative)
- **MCU:** STM32F405 (weaker than H743)
- **Weight:** ~7g (lighter but less capable)
- **Key drawback:** No integrated ESC, fewer UARTs, weaker processor for complex math
- **Verdict:** Stick with H743 — the extra UARTs (7 vs 4) and processing power matter for the ESP32 bridge + GPS + receiver + camera telemetry

**Decision:** MicoAir743v2-AIO-45A is the best choice. The 45A ESC handles the extra servo/pump load.

## 2. MOTORS: 1505 3800KV

### Diatone Mamba Toka 1505 3800KV Specs
- **Stator:** 20mm × 5mm (1505)
- **Weight:** 16.3g each → 65.2g total (4 motors)
- **KV:** 3800KV
- **Rated Voltage:** 3S~4S (12.6V~16.8V)
- **Max Power:** 290W (peak)
- **Peak Current:** 18A
- **Idle Current:** 0.55A@6V
- **Prop:** 3"~4"
- **Mount:** 12×12mm M2
- **Shaft:** 1.5mm
- **Internal Resistance:** 160Ω

### Oscar Liang Motor Table Reference
- The table confirms 1505 motors are recommended for **3-3.5" props on 3S-4S**
- 3800KV on 4S is **hot** — generates significant thrust but runs warm
- For 3.5" props on 4S, many builders prefer **3500KV** for efficiency
- 1505 motors at 3800KV with 3" props on 4S: estimated ~150-200g thrust per motor at full throttle

### Thrust-to-Weight
- Total motor weight: 65.2g
- Estimated total thrust (4 motors): ~600-800g
- Estimated AUW with payload + battery: ~300-350g
- **Thrust-to-weight ratio: ~1.7:1 to 2.3:1** — marginal but flyable
- **Risk:** The water payload + pump adds ~50g. With 850mAh battery (~88g), total AUW could push 350g+. Need to confirm if 1505s can lift this.

**Heads-up:** The Google AI Mode research on "drone water gun" specifically warns: *"Do not try to build this on a micro frame — water is incredibly heavy (1 gram per milliliter)..."*. The research suggests 5" or 7" frames for water payloads. However, the Splash payload target is 15ml water (~15g) + pump + servo = ~50g, which is manageable.

- **Wheelbase:** 171mm
- **Weight:** 87g (without head module)
- **Prop size:** 3-3.6"
- **Motor mount:** 9-12mm
- **Recommended motors:** 1507/1804/2004/2006/2105.5
- **Recommended KV:** 4S 3000-3600kv (Splash uses 3800KV — slightly outside range)
- **Battery max size:** 67×31×40mm
- **Recommended battery:** 4S 750-1100mAh
- **GPS mount:** 18.1×18.1mm (fits GOKU GM10)
- **Camera mount:** O3/O4 Pro heads supported
- **Stack mount:** 25.5×25.5mm (fits MicoAir H743 AIO)
- **Price:** $29.99 (frame only)

### Weight Concern
- Reddit users note the frame is **heavy for its class**: 87g vs ~50g average for 3-3.5" frames
- **60% heavier** than typical 3" frames — this is a critical issue for sub-250g
- Alternative frames to consider:
  - **AOS 3.5 V5** (~40-55g, lighter, good durability)
  - **Flywoo Explorer LR4** (~50g)
  - **DeepSpace Seeker 3** (sub-250g optimized)

**Decision needed:** The Master3X at 87g leaves very little room for battery + payload under 250g. A lighter frame (50-55g range) frees ~30g for battery or water. **Strong recommendation to switch to a lighter 3-3.5" frame.**

## 7. ESP32 WiFi BRIDGE / MCP SERVER

### DroneBridge for ESP32
- **Official ArduPilot support:** https://ardupilot.org/copter/docs/common-esp32-telemetry.html
- **Modes:** Standard WiFi (150m+), ESP-NOW (1km), WiFi LR (1km)
- **Bidirectional:** Serial ↔ WiFi, encrypted (AES-GCM 256)
- **Protocols:** MAVLink, MSP, LTM
- **Supported by:** QGroundControl, Mission Planner
- **Requirements:** Power + UART to FC

### ESP32-S3 MCP Server Architecture
- **MCP Protocol** over WebSockets allows LLM to control drone via tool calls
- **Flow:** LLM → MCP (WebSocket) → ESP32 → MAVLink (UART) → FC
- **Exposed tool examples:**
  - `takeoff(altitude)` → `MAV_CMD_NAV_TAKEOFF`
  - `go_to_gps(lat, lon, alt)` → `SET_POSITION_TARGET_GLOBAL_INT`
  - `get_telemetry()` → parse `GLOBAL_POSITION_INT`, `SYS_STATUS`
  - `orbit(lat, lon, radius)` → `MAV_CMD_NAV_LOITER_TOGGLED` or `MAV_CMD_NAV_CIRCLE`
- **Safety:** ESP32 must validate altitude/geofence constraints before forwarding to FC

### Wiring to FC
- ESP32 UART → FC UART4 (SERIAL4, DMA-enabled MAVLink)
- Power: 3.3V from FC BEC (or 5V if using voltage regulator)
- Ground common

## 8. WATER GUN PAYLOAD

### Micro Pump Options
| Type | Example | Weight | Flow Rate | Voltage | Current | Notes |
|------|---------|--------|-----------|---------|---------|-------|
| Peristaltic | ATO 8ml/min micro | 15g | 2-8 ml/min | 3.7-5V | 0.5W | Self-priming, gentle, low flow |
| Peristaltic | CONQUERALL 150ml/min | ~20g | ≤150 ml/min | 5V | 0.4A (3A surge) | Higher flow, 15g weight |
| Diaphragm | Generic micro diaphragm | ~15g | Variable | 5-12V | Varies | Self-priming, handles pressure |

**Decision:** Peristaltic pump at 15g, 5V, ~0.4A draw. Flow rate ~48-150ml/min sufficient for 15ml reservoir.

### Servo Pan-Tilt
- **SG90 (plastic gear):** 9g, $2, 2.5kg·cm torque — **DO NOT USE** for water nozzle
- **MG90S (metal gear):** 13g, $5, 2.2kg·cm torque — **RECOMMENDED**
- Pan-tilt bracket: FPV nylon dual-axis gimbal (~10-15g)

### Reservoir
- Target: 15ml (syringe-based approach)
- 3D printed or syringe body
- Weight: ~15g when full

### MOSFET Pump Switch
- **IRFZ44N:** Logic level ~4V gate threshold
- **Problem:** ESP32 GPIO 3.3V won't fully turn on IRFZ44N
- **Solution:** Use **IRLZ44N** (logic-level MOSFET, 2V gate threshold) or use driver transistor
- Add flyback diode across pump
- Separate power from FC battery via BEC

### Payload Weight Budget
| Component | Target Weight |
|-----------|--------------|
| Pump (peristaltic) | 15g |
| MG90S servo (pan) | 13g |
| MG90S servo (tilt) | 13g |
| Pan-tilt bracket | 10g |
| Reservoir (15ml) | 15g |
| Nozzle + tubing | 5g |
| MOSFET + wiring | 5g |
| **Total payload** | **~76g** |

**This exceeds the ~50g target budget.** Need to optimize:
- Use one servo (pan only)? Or lighter pan-tilt?
- 3D print custom bracket saves ~5g
- Syringe reservoir is lighter than 3D printed tank

## 9. COMPUTER VISION: YOLOv11 on MacBook M3

### Benchmarks (640×640 resolution)
| Model | YOLOv8 (MPS) | YOLOv11 (MPS) | CoreML Optimized |
|-------|-------------|---------------|-------------------|
| Nano (n) | 60-75 FPS | **75-95 FPS** | **100+ FPS** |
| Small (s) | 40-50 FPS | **50-65 FPS** | 70-85 FPS |
| Medium (m) | 20-28 FPS | **25-35 FPS** | 40-48 FPS |
| Large (l) | 12-15 FPS | **15-20 FPS** | 22-28 FPS |

### Recommendations
- **YOLOv11 Nano CoreML** → 100+ FPS on M3 → excellent for real-time tracking
- Export to CoreML: `model.export(format='coreml')` uses Apple Neural Engine
- Use `device='mps'` with `half=True` for PyTorch MPS backend
- Class filter to `classes=[0]` reduces post-processing overhead
- **Thermal note:** Fanless MacBook Air throttles 15-25% after 5-10 min

### Multi-Person Tracking
- **Kalman Filter + Optical Flow fusion** is the 2026 state of the art
- SAMOFT framework (arxiv 2605.09417) integrates bounding box tracking with pixel-level motion
- Recommended pipeline: YOLOv11 → Kalman filter (constant velocity) → Hungarian association → PID servo control
- Occlusion handling: Pixel Motion Matching (PMM) during occlusion, re-calibrate on re-emergence

### maxboels/TrackingPanTiltCam
- GitHub project: YOLOv8 + pan-tilt servo via serial
- Arduino-based middleware between PC and servos
- PID control loop translates pixel offset to servo PWM
- **Architecture directly applicable to Splash**

## 10. PROTECTION MODE CONCEPT

### Correct Definition (from skill)
- Drone orbits a designated area (e.g., around a protected player)
- If ANY person approaches that area, track them and fire
- **NOT random spraying** — targeted engagement
- Return to orbit after engagement

### Implementation Path
1. **ArduPilot orbit mode:** `MAV_CMD_NAV_CIRCLE` or `MAV_CMD_NAV_LOITER_TOGGLED` — circle around GPS coordinate at set radius/altitude
2. **Geofence:** ArduPilot geofence parameter for protection zone. `FENCE_ACTION=1` (report only), `FENCE_RADIUS` parameter
3. **Person detection:** YOLOv11 detects inbound targets. If target enters geofence radius, switch to track + fire
4. **Return to orbit:** After target leaves zone or is fired upon, re-engage orbit mode
5. **Battery-aware:** Check `SYS_STATUS` battery level. RTB if low

### State Machine
```
IDLE → ARM → TAKEOFF → ORBIT(center, radius, alt) → 
  DETECT(person enters zone) → TRACK(target) → 
    AIM(center target in frame) → FIRE(pump on 0.5s) → 
      RETURN(back to orbit) → ORBIT(...)
```

### Estimated Build Weight (optimistic)
| Component | Weight |
|-----------|--------|
| Frame (Master3X) | 87g |
| FC (MicoAir H743 AIO) | 10g |

| Camera (Hawkeye Thumb) | 16g |

| **Subtotal (no payload, no battery)** | **~201.5g** |

| Component | Weight |
|-----------|--------|
| Battery (4S 850mAh) | 88g |
| Pump | 15g |
| MG90S ×2 | 26g |
| Pan-tilt bracket | 10g |
| Reservoir + water (15ml) | 15g |
| Nozzle + tubing | 5g |
| MOSFET + wiring | 5g |
| **Total** | **~365.5g** |

### Sub-250g Analysis
- Without payload and battery: **201.5g** — OK
- With battery (no payload): **289.5g** — exceeds 250g
- With everything: **365.5g** — well over

### Path to Sub-250g
- **Master3X frame (87g) is the problem** — switch to AOS 3.5 V5 (~45g, saves 42g)
- Use lighter battery: 650mAh (saves 20-30g)
- Use one servo instead of two (saves 13g)
- 3D print bracket instead of commercial (saves 5g)
- **Estimated with lighter frame:** ~278g (still over 250g)

**Reality check:** Sub-250g with water payload is extremely challenging. May need to accept 250-350g AUW. Many sub-250g builds use 1404 motors, smaller batteries, and no payload.

## 12. CRITICAL DECISIONS NEEDED

1. **Frame:** Replace SpeedyBee Master3X with lighter alternative (AOS 3.5 V5 or equivalent)?
   - Weight saving: ~37-42g
   - Cost: ~$35-50

2. **Sub-250g goal:** Is this a hard requirement, or acceptable at 300-350g? Water payload makes sub-250g very difficult.

3. **Servo count:** Dual-axis pan+tilt or single-axis pan-only? Single saves 13g but limits aim.

4. **Pump type:** Peristaltic (15g, lower flow) vs diaphragm (variable, higher flow)?

5. **Onboard CV vs ground-based:** YOLOv11 runs at 100+ FPS on M3 laptop via ESP32 WiFi bridge. But for full autonomy, need onboard companion computer.

6. **Hawkeye Thumb vs lighter option:** Could use a simple camera module (Pi Camera, USB cam) instead of recording camera, saving ~10g.
