### 1.2 ⚠️ Implications for Splash Build
1. **External compass needed**: v2 has NO built-in compass. The GOKU GM10 GPS has a compass — wire SDA/SCL from GPS to FC I2C pads. This was already the plan, so no BOM change.
2. **UART mapping changed**: v1 used UART1 (MAVLink), UART3 (GPS), UART6 (RCIN), UART7 (ESC Telemetry), UART8 (User). **v2 uses**: UART1 (MAVLink2), UART2 (DisplayPort/VTX), UART3 (GPS), UART4 (MAVLink2), UART5, UART6 (RCIN), UART8. **UART7 no longer exists on v2.**
3. **SPL06 barometer**: Different from DPS310. ArduPilot supports both, but verify baro performance — SPL06 may have different noise characteristics.
4. **2-6S support on v2** (v1 was 3-6S). This was already 4S, no impact.

### 1.3 Updated Splash UART Assignment (v2)
| UART | SERIAL# | Peripheral | Notes |
|------|---------|------------|-------|
| UART1 | SERIAL1 | ESP32 WiFi Bridge | MAVLink2, 115200 baud |
| UART3 | SERIAL3 | GPS (GOKU GM10) | GPS protocol, 115200 baud |
| UART6 | SERIAL6 | ELRS Receiver | Now MAVLink protocol (was RCIN), 460800 baud |
| I²C | — | GPS Compass | SCL + SDA from GM10 |

**Key change**: With ELRS MAVLink now production-ready (see §6), UART6 can carry BOTH RC control AND telemetry over a single wire. This frees up UART4 for potential future use (companion computer, optical flow, etc.).

## 2. 🔴 CRITICAL: Hawkeye Thumb 4K — CANNOT Dual-Role (Stream + Record)

### 2.1 The Verdict
**Google AI Mode confirmation**: "No, the Hawkeye Thumb 4K cannot simultaneously stream a 1080p UVC webcam feed over USB and record a 4K file to its internal microSD card."

When connected via USB-C, the camera enters **PC CAM (Webcam) Mode**, which locks the processing chip into a streaming state. Recording to SD is disabled in this mode. The camera must be rebooted to switch modes.

### 2.2 Implications for Splash
**The Hawkeye Thumb 4K is a RECORDING-ONLY camera.** It cannot serve as the CV tracking camera. Splash MUST have a separate camera for computer vision.

## 6. 🔴 MAJOR UPDATE: ELRS MAVLink is Production-Ready

### 6.1 Status Change
Previous report (May 22): "ELRS MAVLink is in development."
**Current status (May 28): ELRS MAVLink is FULLY PRODUCTION-READY since ELRS v3.5.0 (now v4.x).**

### 6.2 What This Means for Splash
- **Single UART** for BOTH RC control AND MAVLink telemetry — no separate telemetry radio needed
- **Single wire** between ELRS RX and FC (RX6 on MicoAir)
- **Full Mission Planner and QGroundControl support** via USB or WiFi (TX Backpack)
- **Parameter editing, mission upload, telemetry** — all over ELRS
- **Stubborn sender** protocol for reliable delivery over long range
- **RC control + telemetry simultaneously** over LoRa

### 6.3 Hardware Requirements
- **ESP-based TX and RX** (any ELRS hardware with WiFi)
- **NOT compatible with STM32-based hardware**
- **2.4GHz strongly recommended** over 900MHz (400 bps vs 4000 bps)
- **Dual-band LR1121** is ideal (4000 bps at K1000Hz)

### 6.4 FC Configuration (ArduPilot)
```
SERIAL6_PROTOCOL = 2     # MAVLink (was RCIN protocol!)
SERIAL6_BAUD = 460        # 460800 baud
RSSI_TYPE = 5
```
All `SR6_*` params = 1 (except SR6_ADSB, SR6_PARAMS, SR6_RAW_CTRL = 0).

**This replaces the previous ELRS CRSF setup** — MAVLink mode is now the recommended configuration for ArduPilot.

### 6.5 Splash-Specific Benefit
- Saves a UART (RC + telemetry on one UART instead of two)
- No need for a separate ESP32 just for telemetry (the ESP32 WiFi bridge can focus on companion computer tasks)
- RC control and GCS telemetry share the same robust LoRa link
- WiFi Backpack allows wireless Mission Planner/QGC connection from phone/tablet

## 7. 🟡 Battery Strategy — LiPo vs Li-Ion

### 7.1 Quick Comparison
| Parameter | 4S LiPo 850mAh | 4S Li-Ion 18650 3000mAh |
|-----------|---------------|------------------------|
| Weight | ~95g | ~200g |
| Capacity | 850mAh | 3000mAh |
| Burst current | 60-80A | 10-20A |
| Flight time (hover) | ~4-5 min | ~12-15 min |
| Voltage sag | Low | High under load |
| Suitability | Freestyle, payload | Long range cruise |

### 7.2 For Splash
**LiPo is mandatory.** The burst current needed for motors + pump (23A peak per Hour 8 power budget) exceeds Li-Ion capabilities. A 4S 650-750mAh LiPo (75-85g) is the sweet spot for sub-250g.

### 7.3 Oscar Liang Rule of Thumb
"Battery should be roughly half the drone's dry weight." For a 175g dry weight (tube frame build), that's ~87g battery. 4S 650mAh is ~75g — close enough.

## 8. 🟢 ESP32-S3 / ESP-IDF Migration Path

### 8.1 Current State
The ESP32-S3 WiFi bridge currently uses Arduino framework (339-line `avatar_bridge.ino`). ESP-IDF with FreeRTOS would unlock dual-core, ESP-NN, and better WiFi performance.

### 8.2 Migration Path
1. ESP-IDF v6.0+ (current stable) provides dual-core SMP FreeRTOS
2. Core 0: WiFi + UDP MAVLink forwarding + WebSocket
3. Core 1: Camera frame capture → CV processing (HSV/YOLO)
4. Minimum task stack: 8KB (proven by esp32-flight-controller)
5. ESP-NN acceleration: 7.2× convolution speedup for AI workloads

### 8.3 Key Reference
ESP-IDF docs: `https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-reference/system/freertos_idf.html`
Migration guide: `https://esphome.io/guides/esp32_arduino_to_idf/`

### 8.4 Alternative: Arduino + FreeRTOS
The Arduino framework runs ON TOP of ESP-IDF FreeRTOS. You can use `xTaskCreatePinnedToCore()` within Arduino sketches for dual-core operation WITHOUT fully migrating to ESP-IDF. This is a lower-friction first step.
