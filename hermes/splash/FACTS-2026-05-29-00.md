## FACT-015: PARALLEL PID + FEEDFORWARD IS OPTIMAL CONTROL LAW
Optimal servo control for SG90/MG90S pan-tilt uses Parallel PID with Velocity Feedforward and Conditional Integration Anti-Windup: u(t) = Kp·e(t) + Ki·∫e(τ)dτ + Kd·de/dt + Kff·v_target(t). Standard Ziegler-Nichols FAILS for micro servos — use manual heuristic tuning (Kp floor → Kd dampening → Ki droop elimination → Kff predictive). SG90 requires LPF alpha=0.2; MG90S allows larger Kd. Source: Google AI Mode (6 sources, PID control law + Python implementation).

## FACT-016: THREAD DECOUPLING IS MANDATORY FOR STABLE TRACKING
CV inference and servo PWM must run on separate threads. Thread 1 (HIGH prio): fixed-rate PID loop at 50Hz. Thread 2 (ASYNC): YOLO detection. Frame drop strategy: always use freshest frame, drop queued frames. Single-threaded sequential execution stacks delays causing control loop destabilization. Apple Silicon: CoreML/MPS backend for PyTorch. Source: Google AI Mode + maxboels/TrackingPanTiltCam codebase.

## FACT-019: DIRECT GPIO BEATS PCA9685 FOR 2-SERVO SPLASH
PCA9685 board adds 2-5g with zero-jitter hardware PWM. But Splash only needs 2 servos (pan+tilt) — MicoAir H743 PWM5/6 direct GPIO is lighter (0g) with adequate jitter performance. PCA9685 justified only for 5+ servo setups. Servo power: NEVER from FC 3.3V/5V rail. Splash's existing 2S 300mAh payload battery already isolates servo current — confirmed good architecture. Source: Google AI Mode (42 sources).

## FACT-020: maxboels/TrackingPanTiltCam IS REFERENCE IMPLEMENTATION
Production-ready YOLOv8 + Kalman + PCA9685 + Arduino tracking system with TWO modes: Surveillance (10-frame buffer, smooth) and Turret (3-frame buffer, exponential weighting, precision aiming). Turret mode maps directly to Splash fire mode. Motion compensation prevents feedback loops between camera movement and detection. Architecture: Python → Serial → Arduino → PCA9685 → Servos. Splash maps to: Python → MAVLink/WiFi → ESP32 → FC UART → PWM5/6 → Servos. Source: GitHub codebase analysis.

## FACT-021: 3D LOCALIZATION IS THE WEAK LINK FOR LEAD CALCULATION
Quadratic intercept requires 3D target position. VL53L1X ToF gives distance only (no XY). Options: (a) Mono+PnP using known human height ~1.7m and bounding box, (b) stereo camera (adds weight), (c) simplified 2D lead using ToF distance + pixel velocity only. This is the #1 technical blocker for accurate auto-aim. Source: Cross-reference with FACT-014 (CV pipeline) + Hour 3 analysis.
