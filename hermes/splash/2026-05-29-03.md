## 1. 🔴 Orbit Waypoint Generation — Splash Protection Mode

### 1.1 MAVLink Orbit Architecture

The **optimal approach** for Splash protection mode orbit is to use **`MAV_CMD_DO_ORBIT`** (command ID: 34) combined with **`SET_POSITION_TARGET_GLOBAL_INT`** for trajectory overrides. A single MAVLink command triggers ArduPilot's native orbit controller — no manual circle-point calculation needed.

```
Protection Mode Flow:
  1. Python/MacBook → MAV_CMD_DO_SET_MODE (mode=4 GUIDED)
  2. Python/MacBook → MAV_CMD_DO_ORBIT (center, radius, velocity)
  3. Python/MacBook → MAV_CMD_DO_SET_ROI_LOCATION (lock camera on center)
  4. Drone circles autonomously — CV thread scans for intruders
  5. On detection → MAV_CMD_DO_SET_MODE (mode=4 LOITER) → track → fire
  6. After engagement → MAV_CMD_DO_ORBIT (resume orbit)
```

### 1.2 MAV_CMD_DO_ORBIT Implementation

```python
# pymavlink: Single command triggers continuous orbit
master.mav.command_long_send(
    target_system,           # Splash drone SYSID (usually 1)
    target_component,        # MAV_COMP_ID_AUTOPILOT1 (1)
    mavlink.MAV_CMD_DO_ORBIT,  # Command ID: 34
    0,                       # Confirmation
    10.0,                    # Param 1: Radius in meters (Splash: 5-15m)
                             #   Positive = clockwise, Negative = counter-clockwise
    5.0,                     # Param 2: Velocity in m/s (0 = use CIRCLE_RATE)
    0,                       # Param 3: Yaw behavior (0=face center, 1=hold heading)
                             #   Splash: 0 (face center for CV scanning)
    0,                       # Param 4: Reserved
    center_lat * 1e7,        # Param 5: Latitude of orbit center (scaled)
    center_lon * 1e7,        # Param 6: Longitude of orbit center (scaled)
    orbit_altitude           # Param 7: Altitude in meters (relative to home)
)
```

### 1.4 Spline Waypoint Entry

For smooth orbit entry (avoiding jerky transitions), use spline waypoints:

```

  MAV_CMD_NAV_WAYPOINT       → Approach point (outside orbit)

  MAV_CMD_DO_ORBIT            → Execute continuous circular loop
```

Set `SPL_ACCEL_TIME` ≥ 1.0 seconds for smooth acceleration vectors.

## 4. 🔴 Person Detection within Geofence

### 4.1 Geofence-Aware Detection Pipeline

The core protection mode logic: **only engage targets INSIDE the defined perimeter.**

```python
def protection_mode_pipeline(frame, fence_center, fence_radius):
    """
    Returns: (target_3d_pos, fire_authorized, new_orbit_center)
    """
    # Step 1: YOLO detection
    detections = yolo_model(frame)  # YOLOv11n, conf ≥ 0.5, class=person

    # Step 2: Filter — only targets within geofence
    valid_targets = []
    for det in detections:
        # Convert pixel coords → world coords (mono+PnP, ToF, or stereo)
        world_pos = pixel_to_world(det.bbox, drone_gps, drone_altitude, gimbal_angles)

        # Check if target is inside protection zone
        distance_from_center = haversine(world_pos, fence_center)
        if distance_from_center <= fence_radius:
            valid_targets.append({
                'world_pos': world_pos,
                'distance': distance_from_center,
                'bbox': det.bbox,
                'confidence': det.confidence
            })

    # Step 3: No valid targets → continue orbit
    if not valid_targets:
        return None, False, None

    # Step 4: Target prioritization
    primary = prioritize_targets(valid_targets)  # → Section 5

    return primary, True, None
```

### 4.2 Coordinate Transformation (Pixel → World)

Three approaches for Splash, ranked by practicality:

| Method | Accuracy | Weight | Latency | Splash Viability |
|--------|----------|--------|---------|-----------------|
| **Mono+PnP** (known height ~1.7m) | ±0.5m at 5m | 0g | ~2ms | ⭐ **PRIMARY** — uses existing CV camera |
| **VL53L1X ToF + pixel** (range + 2D angle) | ±0.3m at 4m | 1g | ~1ms | Secondary — range only, assume ground plane |
| **Stereo camera** | ±0.1m at 5m | +5g | ~5ms | Not viable for sub-250g |

**Mono+PnP approach (from Hour 3 FACT-021):**
- Known person height ~1.7m → bounding box pixel height → distance estimation
- Camera intrinsic matrix from calibration → 3D ray projection
- Combine with drone GPS + gimbal orientation → world position

### 4.3 Direction of Approach Detection

For protection mode, direction matters — only engage **inbound** targets:

```python
def is_inbound(target_pos, prev_positions, fence_center):
    """Check if target is moving TOWARD the protected area"""
    if len(prev_positions) < 3:
        return False  # Not enough data — observe longer

    # Vector from target to fence center
    vec_to_center = fence_center - target_pos
    distance_to_center = np.linalg.norm(vec_to_center)

    # Velocity from Kalman filter (Hour 3 FACT-018)
    velocity = kalman_filter.get_velocity()  # [vx, vy, vz]

    # Dot product: positive = moving toward center
    approach_speed = -np.dot(velocity[:2], vec_to_center[:2]) / distance_to_center

    return approach_speed > 0.3  # m/s threshold (walking speed toward zone)
```

## 5. 🔴 Target Prioritization

### 5.1 Closest-First Strategy (Primary)

When multiple intruders are detected within the geofence:

```python
def prioritize_targets(targets):
    """
    Priority order:
      1. CLOSEST to protected center (most immediate threat)
      2. INBOUND vs outbound (inbound has higher priority)
      3. CONFIDENCE score tiebreaker
    """
    scored = []
    for t in targets:
        score = (
            (1.0 / max(t['distance'], 0.1)) * 100 +  # Distance penalty
            (50 if t.get('is_inbound', False) else 0) +  # Inbound bonus
            (t['confidence'] * 10)                       # Confidence bonus
        )
        scored.append((score, t))

    scored.sort(key=lambda x: x[0], reverse=True)
    return scored[0][1] if scored else None
```

### 6.2 Return-to-Orbit Implementation

```python
def return_to_orbit(orbit_center, orbit_radius, orbit_alt):
    """
    After engagement, fly back to orbit entry point and resume circling.
    Uses spline waypoint for smooth re-entry.
    """
    # Step 1: Fly to orbit entry point (tangent approach)
    entry_point = calculate_orbit_entry(orbit_center, orbit_radius, drone_position)
    master.mav.command_long_send(
        sys, comp, mavlink.MAV_CMD_NAV_WAYPOINT,
        0, 0, 0, 0, 0,
        entry_point.lat, entry_point.lon, orbit_alt
    )

    # Step 2: Wait for arrival (monitor distance to entry)
    # Step 3: Spline onto orbit
    master.mav.command_long_send(
        sys, comp, mavlink.MAV_CMD_NAV_SPLINE_WAYPOINT,
        0, 0, 0, 0, 0,
        orbit_center.lat, orbit_center.lon, orbit_alt
    )

    # Step 4: Resume DO_ORBIT
    master.mav.command_long_send(
        sys, comp, mavlink.MAV_CMD_DO_ORBIT,
        0, orbit_radius, 5.0, 0, 0,
        orbit_center.lat, orbit_center.lon, orbit_alt
    )
```

### 6.3 Orbit Entry Point Calculation

```python
def calculate_orbit_entry(center, radius, current_pos):
    """Find tangent point on orbit circle closest to current position"""
    # Vector from center to drone
    dx = current_pos.lat - center.lat
    dy = current_pos.lon - center.lon
    dist = np.sqrt(dx**2 + dy**2)

    # Normalize and scale to orbit radius
    nx = dx / dist * radius
    ny = dy / dist * radius

    # Entry point on circle perimeter
    return Position(
        lat=center.lat + nx,
        lon=center.lon + ny
    )
```

## 7. 🔴 Battery-Aware Abort & RTB

### 7.1 ArduPilot Battery Failsafe — Splash Configuration

Based on Google AI Mode research (6 sources) and ArduPilot official docs:

**4S 850mAh LiPo — Splash-specific parameters:**

| Parameter | Splash Value | Description |
|-----------|-------------|-------------|
| **`BATT_MONITOR`** | `4` | Voltage + current sensing |
| **`BATT_CAPACITY`** | `850` | 850mAh battery capacity |
| **`BATT_LOW_VOLT`** | **`13.6`** | Trigger at 3.4V/cell under load (conservative for sub-250g) |
| **`BATT_CRT_VOLT`** | **`13.2`** | Critical at 3.3V/cell — immediate land |
| **`BATT_FS_LOW_ACT`** | `2` | **RTL** on low battery |
| **`BATT_FS_CRT_ACT`** | `1` | **Land** on critical battery |
| **`BATT_LOW_TIMER`** | `10` | 10-second sustained low before trigger (avoids false triggers from punch-outs) |
| **`BATT_CRT_TIMER`** | `5` | 5-second sustained critical before landing |

**Why 13.6V instead of 14.0V:**
- Splash is sub-250g with lighter amp draw than standard builds
- 3.4V/cell leaves ~20% capacity → sufficient for RTL from 200m radius at 5 m/s
- Standard 3.5V/cell (14.0V) is conservative but reduces usable flight time by ~30s
- For Senior Assassins (short engagements), 13.6V is adequate with RTL margin

### 7.2 Splash Companion Computer Battery Monitoring

The MacBook/ESP32 also monitors battery for protection mode decisions:

```python
def check_battery_safety(battery_voltage, battery_remaining_pct):
    """
    Protection mode battery safety:
      - >30% remaining: Full protection mode active
      - 20-30% remaining: Only engage if target within 3m (close range)
      - 15-20% remaining: Orbit only — no engagement. RTB triggered.
      - <15% remaining: Immediate RTB — override all engagement
    """
    if battery_voltage < 14.0 or battery_remaining_pct < 15:
        return "RTB_IMMEDIATE"  # BATT_FS_LOW_ACT will also trigger

    if battery_remaining_pct < 20:
        return "ORBIT_ONLY"  # Patrol but don't engage

    if battery_remaining_pct < 30:
        return "ENGAGE_CLOSE_RANGE"  # Only fire if target < 3m

    return "FULL_PROTECTION"
```

### 7.3 Protection Mode Endurance Estimate

| Component | Current Draw |
|-----------|-------------|
| 4× 1505 3800KV motors (hover) | ~12A |
| FC + sensors | ~0.3A |
| GPS (GOKU GM10) | ~0.05A |
| ESP32-S3 WiFi bridge | ~0.3A |
| ELRS RX | ~0.1A |

**Flight time estimation (850mAh, 80% usable = 680mAh):**
- Hover only (orbit): 680/13300 × 60 ≈ **3.1 minutes**
- With 5 burst fires (200ms each @ 15.3A): ≈ **2.8 minutes**
- **RTL reserve needed: ~30 seconds** → **usable protection time: ~2-2.5 minutes**

⚠️ **This is SHORT.** For Senior Assassins, a 2-3 minute protection window is sufficient for a single engagement scenario (e.g., protecting a player as they cross a courtyard). For extended protection, swap to a larger battery (4S 1300mAh adds ~40g) or plan for multiple sorties.

### 7.4 Battery Sag Under Load — Protection Impact

During pump firing (2A burst), battery voltage may sag temporarily below BATT_LOW_VOLT. The `BATT_LOW_TIMER = 10` second delay prevents false RTL triggers. However, if the battery is already low (3.5V/cell), a pump burst could push it below BATT_CRT_VOLT, triggering immediate landing.

**Mitigation:**
- Companion computer checks `battery_voltage - sag_estimate` before authorizing fire
- If predicted sag crosses BATT_CRT_VOLT → deny fire, RTB immediately
- `BATT_CRT_TIMER = 5` provides 5-second buffer for short bursts
