## Key Wiki Lessons Applied to Splash

1. **Direct-solder motors**: Skip bullet connectors. Solder 1505 motor wires directly to ESC pads. Saves weight AND prevents vibration-induced disconnection.
2. **Buy 5 motors**: Order one spare. Budget motor QC is inconsistent.
3. **Validate layers independently**: Phase 0 (bench) → Phase 1 (tethered) → Phase 2 (dry autotune) → Phase 3 (payload) → Phase 4 (autonomous). Each gates the next.
4. **Simulate first**: ArduPilot SITL + Gazebo for CV tracking development before risking hardware.
5. **Quality components**: MicoAir H743 is quality tier (not budget). Good choice.
