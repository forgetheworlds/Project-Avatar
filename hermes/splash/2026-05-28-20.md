### 1.5 Pump & Servo Power Wiring

⚠️ **Critical: Pump brownout risk identified in May 22 synthesis.**

```
2S 300mAh LiPo → MOSFET IRFZ44N Gate (FC PWM7 signal)
                    │
                    ├── Drain → Pump (+) → Pump (−) → GND
                    └── Source → GND

Protection:
  - 1000µF capacitor on pump power rail (inrush buffering)
  - 10A quick-blow fuse inline
  - Flyback diode across pump terminals
  - Current sensing: INA219 on I2C (optional, for stall detection)
```

| Component | Weight (g) | CG Position (Y from nose, mm) | Moment (g·mm) |
|-----------|-----------|-------------------------------|---------------|
| Frame + FC stack (bare) | ~70 | 50 (center) | 3,500 |
| Motors (4× 1505) | ~60 | 50 (at arms) | 3,000 |
| 4S 850mAh LiPo | ~95 | 65 (rear-shifted) | 6,175 |
| Hawkeye Thumb 4K (front) | ~17 | 15 | 255 |
| ESP32-S3 bridge | ~8 | 40 | 320 |
| GPS (GOKU GM10 V3) | ~5 | 85 | 425 |
| ELRS receiver | ~2 | 75 | 150 |
| Payload: Pump | 15 | 35 | 525 |
| Payload: MG90S ×2 | 18 | 40 | 720 |
| Payload: Reservoir (full) | 20 | 35 | 700 |
| Payload: Nozzle + wiring | 5 | 30 | 150 |
| **TOTAL** | **~315g** | — | **15,920** |

### 2.2 CG Calculation

For a typical 3" Master3X frame (~130mm wheelbase), the geometric center is at ~50mm from nose:

```
Y_cg = Σ(m_i × Y_i) / M_total = 15,920 / 315 = 50.54 mm
```

**Offset: +0.54mm forward** — well within the <5mm acceptable range for sub-250g drones. The LiPo battery at Y=65mm provides counterweight to the front payload (camera + water gun at Y=15-35mm).

### 2.3 CG Tuning Strategy
- **Dry (no water):** Shift LiPo rearward until frame hangs level at geometric center
- **Full (15ml water):** CG shifts forward ~2mm — within tolerance. Battery stays fixed.
- **Dynamic (during firing):** CG shifts toward rear as water depletes. ArduPilot's `ATC_RAT_*_I` integral term handles slow CG drift.
- **Vertical (Z-axis):** Keep payload as close to prop plane as possible. Bottom-mount battery preferred for high-speed pitch stability.

### 2.4 Physical Verification
1. Loop dental floss under top plate at calculated CG (50mm)
2. Lift — frame should hang level
3. Adjust battery strap position until balanced
4. Full payload test: fill reservoir, repeat balance check

### 3.3 Tuning Sequence (Methodical Approach)

Following ArduPilot MethodicConfigurator best practices:

1. **Pre-flight config**: Flash latest ArduCopter (4.5.x), set frame type, calibrate sensors
2. **Static checks**: Motor direction, ESC protocol (DShot300), accelerometer calibration
3. **First hover (Stabilize)**: Check vibration levels (`VIBE.*` < 15), adjust harmonic notch
4. **Throttle controller**: Set `MOT_THST_HOVER` from hover data
5. **Harmonic notch filter**: Use ArduPilot Filter Review Tool on hover log
6. **Quiktune (Lua)**: If H743 supports Lua, run VTOL-Quiktune first
7. **Autotune sequence**: Roll → Pitch → Yaw → YawD → Roll/Pitch retune
8. **System ID** (optional): For analytical PID optimization
9. **Position controller**: Tune XY velocity after rate loops
10. **Everyday use**: Increase `ATC_THR_MIX_MAX` to 0.9

## 4. 🔴 Flight Test Plan

### 4.1 Phase 0: Bench Testing (No Props)

| Step | Test | Success Criteria |
|------|------|------------------|
| 0.1 | Power all systems via USB + battery | No smoke, correct voltages |
| 0.2 | Sensor calibration (accel, gyro, compass, baro) | All green in Mission Planner |
| 0.3 | Radio calibration (ELRS CRSF) | All channels respond, failsafe works |
| 0.4 | GPS lock test (outdoors) | HDOP < 1.0, 10+ satellites in <2min |
| 0.5 | ESP32 telemetry link | QGC/Mission Planner connects via WiFi |
| 0.6 | Servo sweep test (PWM5,6) | Full pan-tilt range, no binding |
| 0.7 | Pump test (PWM7 via MOSFET) | Pump activates, no brownout |
| 0.8 | Failsafe test (radio off, GCS disconnect) | RTL triggers correctly |

### 4.2 Phase 1: Tethered Hover

```
Setup:
  - Ceiling anchor → bungee cord → drone CG point
  - Floor anchor → slack power/data tether
  - Soft grass surface, no wind (<2 m/s)
  - Empty reservoir (dry flight)

Procedure:
  1. Arm in STABILIZE mode
  2. Slowly raise throttle until liftoff
  3. Hover at 50cm within tether limits
  4. Observe: oscillations? drift? motor temperature?
  5. Kill switch test: immediate disarm
  6. Repeat 3× for confidence

Success: Stable hover, no oscillations, VIBE.* < 15 in logs
```

### 4.3 Phase 2: Dry Flight Autotune

```
Setup:
  - Open field, no wind (<3 m/s), soft grass
  - Empty reservoir
  - Full battery

Procedure:
  1. Take off in STABILIZE, switch to ALTHOLD at 3m
  2. Engage AUTOTUNE (roll for 2-3 min → pitch for 2-3 min)
  3. Land, save gains, swap battery
  4. Repeat for yaw axis, then yaw D
  5. Final retune: roll + pitch together
  6. Test in all flight modes: STABILIZE, ALTHOLD, LOITER, POSHOLD, RTL

Success: ATC_ANG_*_P ≥ 4.5, ATC_RAT_*_D > AUTOTUNE_MIN_D
```

### 4.4 Phase 3: Payload Integration

| Step | Description | Duration |
|------|-------------|----------|
| 3.1 | **Half-full slosh check**: Fill reservoir 50%, hover. Input sharp stick pulses to trigger fluid movement. Increase `ATC_RAT_*_I` if wobbling. | 1 battery |
| 3.2 | **Full load hover**: Fill 100%, verify `MOT_THST_HOVER` < 0.60. Check motor/ESC temperatures. | 1 battery |
| 3.3 | **Pan-tilt activation**: While hovering, sweep pan ±90°, tilt ±45°. Watch for pitch/roll coupling. | 1 battery |
| 3.4 | **Dry fire test**: Fire pump while hovering (no water). Verify no PWM glitches, no FC brownout. | 1 battery |
| 3.5 | **Static fire test** (on ground, armed): Fire water gun at target 2m away. Verify stream trajectory. | Ground test |
| 3.6 | **Dynamic discharge test**: Hover + fire continuously. ArduPilot must handle 100%→0% mass transition. Monitor logs for oscillations. | 2 batteries |

### 4.5 Phase 4: Autonomous Modes

| Step | Description | Success Criteria |
|------|-------------|------------------|
| 4.1 | **Orbit mode**: LOITER at 3m, test circle waypoints | Stable orbit, GPS position hold |
| 4.2 | **CV integration (tethered)**: MacBook receives ESP32-CAM stream, runs YOLOv11n, sends MAVLink servo commands via ESP32 bridge | Servos track bounding box center |
| 4.3 | **Auto-track (dry)**: Fly to GPS point, MacBook identifies person, servos track, pump fires on command | Full pipeline functional |
| 4.4 | **Protection mode (simulated)**: Orbit waypoint, MacBook detects "intruder", tracks, fires, returns to orbit | State machine transitions correct |
| 4.5 | **Full mission (live fire)**: Complete "identify → track → fire → RTB" with water payload | Successful hit on target |

### 4.6 Emergency Procedures (Every Flight)

```
LOST LINK:     FS_GCS_ENABLE triggers RTL after 5s — ALWAYS TEST BEFORE FLIGHT
LOW BATTERY:   BATT_LOW_VOLT = 14.0V triggers land warning
               BATT_CRT_VOLT = 13.6V triggers immediate land
KILL SWITCH:   Aux switch → immediate DISARM (configure RCx_OPTION)
MOTOR FAILURE: Immediate DISARM, accept crash — don't fight it
FLYAWAY:       If RTL doesn't engage, DISARM at low altitude over soft surface
```

## 5. 🔴 Failure Modes & Protection

### 5.1 Water Damage — Electronics Protection

| Component | Risk | Protection |
|-----------|------|------------|
| **FC (MicoAir H743)** | Short circuit, trace corrosion | **Silicone conformal coating** (MG Chemicals 422B). Mask barometer hole and connectors. |
| **ESC 4-in-1** | High-current short, MOSFET burnout | **Silicone conformal coating** (high temp tolerance). Heat shrink wrap over coated board. |
| **ESP32-S3** | WiFi antenna detuning from coating | **Acrylic coating** (thinner, less RF impact). Keep antenna zone clear. |
| **GPS module** | Ceramic antenna detuning | **No coating on antenna**. Only coat PCB edges and connector. |
| **ELRS receiver** | Antenna detuning | **No coating on antenna element**. Heat shrink wrap over coated PCB. |
| **Battery connector** | Galvanic corrosion | **Hydrophobic spray** (CorrosionX) on contacts. Gold-plated XT30 preferred. |

### 5.2 Mechanical Failure Modes

| Failure | Cause | Mitigation |
|---------|-------|------------|
| **Pump stall** | Debris in nozzle, impeller jam | 60-micron mesh intake filter. Electronic current limiting (INA219 + software cutoff at 2A). Inline 2A quick-blow fuse. |
| **Servo jam (MG90S)** | Water in gearbox → rust → gear strip | **Synthetic marine grease** packed in gearbox. **O-ring seal** on output shaft. IP67-rated servo upgrade if budget allows ($8-12 each). |
| **Servo linkage failure** | 3D printed horn strips under load | Use metal servo horns. Design breakaway mount (shear pins) so servo doesn't take full crash force. |
| **Reservoir leak** | Cracked tank, loose fitting | Double-seal all fittings with silicone RTV. Pressure test to 2× operating pressure before flight. |
| **Propeller strike** | Target too close, obstacle collision | Prop guards mandatory for all autonomous flights. 3" cinewhoop ducts recommended. |
| **Motor desync** | Autotune demands rapid RPM changes on low-KV motors | DShot300 (digital, more reliable timing). `MOT_SPIN_MIN` > 0.15. ESC with BLHeli_32. |

### 5.3 CV Pipeline Failures

| Failure | Cause | Mitigation |
|---------|-------|------------|
| **Target loss** | Occlusion (tree, building) | Kalman prediction maintains track for 1-2 seconds. ByteTrack keeps low-confidence detections. |
| **False positive track** | CV mistakes tree/sign for person | Confidence threshold ≥ 0.5 for fire authorization. Require N consecutive detections before tracking. |
| **Lighting failure** | Below 15 lux (dusk/dawn) | Abort autonomous mission. Return to manual control. Log warning. |
| **WiFi dropout** | ESP32 range exceeded | ESP-NOW LR mode (1km range). Failsafe: hover + reconnect, then RTL if >10s no link. |
| **Latency spike** | MacBook CPU throttled | Monitor FPS. If < 30 FPS, degrade to STABILIZE + manual fire only. |

### 5.4 Post-Flight Water Exposure Protocol

```
1. IMMEDIATELY disconnect battery after landing
2. Inspect all electronics for visible water droplets
3. Blow compressed air (low pressure) across all PCBs
4. If water ingress detected:
   a. Flush affected board with 99% isopropyl alcohol
   b. Allow to dry for minimum 30 minutes
   c. Inspect under magnifier for corrosion spots
5. Check servo gearboxes for water — regrease if needed
6. Drain and dry reservoir completely
7. Run pump with clean water for 10 seconds to flush
8. Log any water exposure in maintenance record
```

## 6. 🔴 Weather Constraints

### 6.1 Splash Operational Envelope

| Condition | Limit | Reason |
|-----------|-------|--------|
| **Wind speed (sustained)** | **< 5 m/s** (11 mph) | Sub-250g drone stability. 75% CV rule: tracking degrades at 8 m/s but sub-250g can't handle it. |
| **Wind gusts** | **< 8 m/s** (18 mph) | Momentary loss of position hold acceptable, but no firing during gusts. |
| **Rain / precipitation** | **NONE** | Splash electronics are NOT IP-rated. Even light drizzle risks short circuits. |
| **Humidity** | **< 85%** | Above 85%, condensation risk on cold electronics after flight. |
| **Temperature** | **5°C – 35°C** | Battery performance drops below 5°C. ESC/FC overheat risk above 35°C (no active cooling). |
| **Lighting (CV minimum)** | **≥ 15 lux** | Below 15 lux, YOLOv11n person detection F1-score drops below 0.7. |
| **Lighting (CV optimal)** | **100 – 10,000 lux** | Overcast sky ideal. Direct sunlight causes harsh shadows — CLAHE preprocessing required. |
| **Lighting (time of day)** | **Civil dawn to civil dusk** | No night operations without IR camera (not in Splash scope). |

### 6.2 Pre-Flight Weather Checklist

```
□ Wind speed measured at flying site: < 5 m/s (use anemometer or weather app)
□ No rain in forecast for next 30 minutes
□ Lighting: daylight operation only (sun altitude > 6° above horizon)
□ Temperature within 5-35°C range
□ Ground is dry (wet grass = splash risk on landing)
□ CV test: point camera at target, verify YOLO detects person at 3m range
```

### 6.3 Battery Endurance Estimates

Based on community 1505/3800KV + 4S 850mAh builds (~350g AUW):

| Flight Mode | Estimated Time | Notes |
|-------------|----------------|--------|
| Hover only (no payload) | 8–10 min | ~7A draw |
| Hover with full payload (315g) | 6–8 min | ~9A draw, throttle ~40% |
| Mixed flight (orbit + track) | 5–7 min | Motors working harder |
| Full mission (orbit + track + fire) | 4–6 min | Pump adds ~1.5A intermittent |
| RTL reserve | 2 min minimum | Land at BATT_LOW_VOLT = 14.0V |

⚠️ **High wind reduces endurance by 30-50%.** In 5 m/s wind, expect 3-4 min usable mission time.

## 9. Key Facts for Holographic Memory

1. **MicoAir H743 provides 11 PWM outputs across 4 groups with DShot on all channels.** Splash mapping: PWM1-4=motors, PWM5=pan servo (SERVO5_FUNCTION=6 Mount Yaw), PWM6=tilt servo (SERVO7=7 Mount Pitch), PWM7=pump MOSFET (SERVO7_FUNCTION=22 Sprayer Pump). Groups share output protocol — Group 2 (PWM5-6) can be standard 50Hz servo PWM while Group 1 (PWM1-4) runs DShot300. 8 UARTs: UART1=ESP32 MAVLink, UART3=GPS, UART6=ELRS CRSF.

2. **Splash CG at 50.54mm from nose — within 1mm of geometric center.** Total AUW ~315g (70g frame+stack, 60g motors, 95g battery, 17g camera, 58g payload). Battery positioned at Y=65mm (rear-shifted) counterbalances front payload (camera at Y=15mm, water gun at Y=35mm). CG shifts <2mm during water discharge — well within ArduPilot's integral correction capability. Physical balance verification: dental floss lift test at calculated CG point.

3. **Five-phase flight test plan required for safe Splash integration:** Phase 0 (bench: sensor cal, servo sweep, failsafe test) → Phase 1 (tethered hover with bungee anchor, empty payload) → Phase 2 (dry autotune: roll→pitch→yaw→yawD→retune) → Phase 3 (payload: half-full slosh check, full load hover, pan-tilt coupling test, dynamic discharge) → Phase 4 (autonomous: orbit→CV track→fire→RTB). Each phase gates the next. Emergency: DISARM on kill switch, RTL on lost link, land on low battery.

4. **ArduPilot parameters tuned for sub-250g with payload:** INS_GYRO_FILTER=30Hz (for 3" props), INS_HNTC_ENABLE=1 (harmonic notch mandatory), ATC_ANG_PIT_P=6.0 (base), ATC_RAT_PIT_P=0.12 (conservative start), MOT_THST_HOVER target <0.60 with full load. AUTOTUNE_AGGR=0.075 (medium aggression for payload). Payload-specific: MNT1_TYPE=1 (servo gimbal), RNGFND1_TYPE=36 (VL53L1X), FLOW_ENABLE=1 (PMW3901 indoor fallback). MethodicConfigurator recommended for systematic tuning.

5. **Waterproofing strategy: silicone conformal coating (MG Chemicals 422B) on FC, ESC, and non-RF sections of ESP32.** Acrylic coating (419D) on ESP32 antenna-adjacent areas to minimize RF detuning. GPS antenna zone left uncoated. MG90S servos packed with synthetic marine grease + O-ring on output shaft (or upgrade to IP67-rated servo). Pump protected by 60-micron mesh intake, INA219 current monitoring with 2A software cutoff, and 1000µF capacitor on power rail. Post-exposure protocol: IPA flush, 30-min dry time, magnifier inspection.

6. **Operational weather envelope: wind <5 m/s sustained (sub-250g limit), gusts <8 m/s, NO precipitation (no IP rating), lighting ≥15 lux (YOLOv11n minimum), 5-35°C.** 75% CV rule: tracking degrades above 75% of drone's max wind resistance (5×0.75=3.75 m/s for reliable CV). High wind cuts endurance by 30-50%. Mission endurance: 4-6 min with full payload + firing, 2 min RTL reserve. Civil dawn to civil dusk only — no night ops without IR camera.

7. **ESP32-S3 WiFi bridge via DroneBridge firmware provides bidirectional MAVLink at up to 1km range (ESP-NOW LR mode), <8g weight.** Wired: UART1 (115200 baud, MAVLink2) to FC. On MacBook ground station side: second ESP32-S3 as ground unit. ESP-NOW LR Mode AIR (vehicle) + GND (ground station). Standard WiFi mode also available (150m range) for shorter-range testing. ESP32-CAM streams separate MJPEG video for CV processing — two ESP32 modules on drone (one for telemetry, one for camera) OR single ESP32-S3 if Hawkeye can't stream.

8. **Complete system integration: onboard drone (FC + payload + camera + ESP32 bridge) ↔ WiFi/ESP-NOW ↔ MacBook M3 ground station (YOLOv11n + ByteTrack + Kalman + Servo PID) ↔ MAVLink servo commands via ESP32.** Three data paths: (1) ESP32-CAM → MacBook: MJPEG video stream, (2) ESP32-S3 ↔ MacBook: Bidirectional MAVLink (telemetry + commands), (3) MacBook → ESP32-S3 → FC: Servo commands via MAVLink COMMAND_LONG or RC_CHANNELS_OVERRIDE. Total pipeline latency target: <50ms (CV: ~12ms, WiFi: ~20ms, MAVLink: ~10ms, servo mechanical: ~5ms).
