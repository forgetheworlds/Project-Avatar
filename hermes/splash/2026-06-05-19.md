## §2. 🔴 CRITICAL: FAA Legal & Regulatory Analysis

**Source:** Google AI Mode (6 sources incl. FPVFC, FAA.gov, TheDroneU)

### The Sub-250g "Exemption" is Narrower Than Assumed

| Rule | Recreational (<250g) | Part 107 (<250g) |
|------|-------------------|------------------|
| Registration | **Exempt** (if strictly recreational) | **Required** ($5, any weight) |
| Remote ID | **Exempt** (<250g recreational) | Required |
| TRUST Test | **Required** (free online) | Required (plus Part 107 exam) |
| Fly over people | **PROHIBITED** regardless of weight | Only Category 1-4 allowed |
| Drop payloads | **PROHIBITED** (hazard to persons) | Restricted (waiver needed) |

### CRITICAL FINDINGS FOR SPLASH:

1. **Water payload drops = federal violation.** FAA regulation § 107.23 prohibits dropping anything that creates an undue hazard. Water from a drone at 3m qualifies. This applies to BOTH recreational and Part 107 operations.

2. **Sub-250g exemption is only for registration + Remote ID.** All other safety rules (not flying over people, not dropping objects) still apply at ANY weight.

3. **Payload weight can void exemption:** If water + pump + servo pushes total AUW over 249g (which Splash does at ~315g), registration is mandatory regardless.

4. **Flying over people is always prohibited for recreational pilots.** Even at sub-250g. Even with prop guards. The only exception is Part 107 Category 1 (sub-250g, no exposed rotating parts that can lacerate). Props count as "exposed rotating parts" — adding prop guards likely pushes over 250g.

5. **Senior Assassins context:** Operating on a university campus adds state/local regulations. Some states have explicit drone-on-campus restrictions. Check local bylaws.

### Action Required:
- **Splash likely needs to either:**
  (a) Operate on private property with explicit consent from all participants (participants consenting to being sprayed)
  (b) Obtain Part 107 certification + waiver for payload dropping
  (c) Stay sub-250g (requires frame swap + lighter components) AND operate with consent in private area
- **Document everything:** Written consent forms, brightly colored drone, clear markings, no public/stadium operations
- **Previous Canadian legal context (F-2026-06-03-060) still stands** — Transport Canada equivalent restrictions

### Optimal Build Specs for Custom Frame

| Parameter | Specification |
|-----------|--------------|
| **Tubular boom stock** | 6mm OD pultruded carbon fiber round tubes |
| **Hub filament** | Carbon fiber nylon (PA-CF) or PETG-CF |
| **Hub infill** | 100% solid on motor mounts, 50% gyroid on core clamps |
| **Anti-rotation** | M2 through-hole pins to lock carbon rod to bracket |
| **Motor mount** | Integrated into arm tips or separate printed clamps |
| **FC mounting** | 25.5×25.5mm or 20×20mm pattern on central hub |
| **Expected frame weight** | ~15-25g (vs Master3X at 87g) — **saves 62-72g** |

### Weight Savings Analysis
- **Current Master3X frame:** 87g bare, 145g fully assembled
- **Custom tube frame:** 15-25g + hardware
- **Weight saved:** ~62-72g (or ~120g vs full Master3X assembly)
- **This single swap enables sub-250g Splash:** AUW with tube frame = ~243-260g vs ~315g with Master3X
- Combined with lighter battery (4S 550mAh vs 850mAh), **sub-250g is achievable** with tube frame

### Reference Build for Design

## §5. 🟢 NEW: Geofrancis Build Detailed Reference

**Source:** ardupilot.org forum thread 115400

**Build specifics:**
| Component | Choice | Weight |
|-----------|--------|--------|
| Frame | Custom 6mm carbon tube (2mm wall) | ~15g (can reduce to 9g with ultralight tube) |
| FC | SpeedyBee F405 Mini | ~5g |
| Motors | 1404 3800KV (lighter than 1505) | ~10g each |
| Props | 3" bi-blade | ~2g set |
| GPS | GOKU GM10 | 2.5g |
| Battery | 2S 5500mAh Li-Ion (18650 cells) | ~95g |
| **Total AUW** | | **~248g** |

**Key lessons for Splash:**
1. **Ultralight carbon tube** (9-15g) is better than carbon plate frames (50-87g)
2. **Spacedrone-style 3D-printed hub clamps** verified as field-reliable
3. **SpeedyBee F405 Mini** is lighter than MicoAir H743 (5g vs 10g) but has less UART capacity
4. **2S Li-Ion** for endurance vs **4S LiPo** for power — Splash needs 4S for 1505 motor KV
5. **Sub-250g IS achievable** — need tube frame + 1404/1504 motors + slim payload

**Splash tube frame adaptation:**
- Use Spacedrone or GrabCAD hub design as base
- Enlarge for 25.5×25.5mm AIO (MicoAir H743 v2)
- Extend arms for 3.5" props (need ~130mm diagonal motor-motor)
- Add pump/servo mounting plate under central hub
- Total custom frame BOM: 6mm carbon tube (~$5) + PETG-CF filament (~$3) = **~$8** vs $30-42 for Master3X
