## §3. 🟢 Coreless Gear Pump Reassessment

The coreless gear pump (12-15g) remains the **only viable path to sub-250g** but with mission-critical tradeoffs:

**Pros:**
- 12-15g total pump weight (saves 53g vs S18 EL)
- 400-600 mL/min flow rate
- Enables sub-250g build with tube frame
- DIY-buildable from 12mm coreless motor + PEEK/PPS housing

**Cons:**
- Only 1-1.5m range (vs 2-4m target)
- Weak self-priming — requires gravity-fed placement
- DIY-only — no COTS option
- Untested pressure consistency

**Recommendation for v1:** Accept >250g AUW and use S18 EL (68g) for 2-4m range. Register the drone if required (>250g). Sub-250g can be a v2 optimization target using a proven coreless gear pump.

## §4. 🟢 Protection Mode Reference Implementation

**Source:** Google AI Mode — "drone YOLO auto aim protection mode orbit track person geofence ArduPilot implementation Python"

Found a **complete Python reference implementation** with:

**Architecture:**
- Companion computer (RPi5/Jetson) ↔ ArduPilot FC via UART
- DroneKit-Python for MAVLink commands
- YOLOv8n/v11n for person detection
- Polygon geofence via Shapely

**Key Implementation Details:**
```
1. Geofence Check → Exit/Yaw correction → Distance mgmt → Orbit velocity → MAVLink
2. YOLO person detection → bounding box center → yaw_rate PID
3. SET_POSITION_TARGET_LOCAL_NED for velocity/yaw control
4. GEOFENCE_POINTS as polygon → Shapely.contains() → RTL on violation
```

**Adaptation to Splash:**
- Replace DroneKit with direct pymavlink (already planned)
- Add water trigger: on target lock (>1.5s center-frame) → send SERVO_SET for pump MOSFET
- Protection mode: combine orbit (MAV_CMD_DO_ORBIT) + geofence detection + track-and-fire
- State machine integration: IDLE → ORBIT → DETECT → TRACK → AIM → FIRE → RETURN

**Libraries used:** ultralytics, dronekit, pymavlink, opencv-python, numpy, shapely
