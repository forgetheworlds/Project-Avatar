### ⚠️ CRITICAL CORRECTION: Sub-250g REASSESSMENT

**The earlier May 22-29 research claimed sub-250g was the target. However, with the actual component weights tallied, Splash cannot achieve sub-250g AUW.** The payload is simply too heavy:

- 4S 850mAh alone: ~88g
- Two MG90S servos: ~27g
- 12V micro diaphragm pump: ~18g
- Hawkeye Thumb + ESP32-CAM: ~22g
- Frame itself: 26g
- Motors: 56g
- FC: 10g
- GPS + RX: ~4g
- Hardware: ~12g

**Total dry airframe ~218g + 88g battery = 306g minimum without water.**

**If sub-250g is a hard requirement**, the following sacrifices must be made:
1. Remove water payload entirely (defeats Splash purpose)
2. Switch to 3S 550mAh battery (~50g savings, but halves flight time)
3. Remove Hawkeye Thumb 4K (-17g) — rely solely on ESP32-CAM for both CV + FPV
4. Use SG90 instead of MG90S (-8g total) — but risks stripped gears
5. Switch to 1404 motors (-12g total) — but loses thrust margin
6. Use geofrancis carbon tube frame (-14g savings over Crux35)

**With ALL sacrifices**: ~218g - 17g - 8g - 12g - 14g - 30g (battery) = ~137g. But then water + pump + servo + reservoir still adds ~58g, plus 3S 550mAh ~58g = ~253g. **Still over 250g. Sub-250g is impossible for a water-carrying drone.**

**Recommendation: Accept >250g AUW** — Senior Assassins is a low-stakes game environment, not FAA-regulated commercial operation. The drone is flown in private spaces (courtyards, fields). At ~306g dry / ~356g with water, the flight characteristics are perfectly safe and the 610-650g per motor thrust provides a comfortable 7:1 thrust-to-weight ratio.

### Alternative: Go Carbon Tube for v2 Weight Reduction

If weight optimization is critical for a future revision:

- **geofrancis-style frame**: ~12-15g (vs 26g Crux35)
- **Savings**: ~11-14g
- **Cost**: Scratch-build complexity, no mounting patterns, no crash protection

## §2. 🟢 SERVO PID GAP CLOSED: MG90S Specification + PID Tuning

### MG90S vs SG90 — Complete Comparison

| Specification | SG90 | MG90S | Winner |
|--------------|------|-------|--------|
| **Gear Material** | Plastic (polycarbonate) | **Aluminum/metal** | MG90S |
| **Bearings** | Plain bushing | **Double ball bearings** | MG90S |
| **Weight** | 9.0g | 13.4g | SG90 |
| **Stall Torque @ 4.8V** | 1.8 kg·cm | **2.0 kg·cm** (+11%) | MG90S |
| **Stall Torque @ 6.0V** | 2.2 kg·cm | **2.5 kg·cm** (+14%) | MG90S |
| **Speed 60° @ 6V** | 0.10 sec | **0.08 sec** (25% faster) | MG90S |
| **Stall Current** | ~650mA | ~800mA | SG90 |
| **Backlash/Slop** | High (flexes under load) | **Low** (precision) | MG90S |
| **Durability** | Strips under rapid reversal | **Metal gears handle reversal** | MG90S |
| **Price** | ~$2 | ~$3 | SG90 |

### Decision: MG90S for BOTH pan-tilt AND pinch valve

**Rationale for pan-tilt:** CV tracking requires rapid direction reversal. The plastic SG90 gears strip under the momentum of a pan-tilt mount with camera + nozzle assembly. The MG90S metal geartrain with double ball bearings provides the structural stiffness needed for PID position loop convergence. MG90S at 6V (via 2S payload battery step-down to 5V UBEC) provides 2.5 kg·cm — sufficient for a 5cm lever arm (functional load ~50g, typical camera + nozzle load ~30-35g).

**Rationale for pinch valve:** The MG90S must apply sustained torque to pinch silicone tubing under 4-12 PSI pump pressure. Metal gears won't strip or deform over repeated open/close cycles. SG90 plastic teeth would deform under sustained load.

### PID Tuning Protocol for Micro Servos (from Google AI Mode research)

**Outer-loop PID** (pixel error → servo angle):

```
                  +--------+     Angle / PWM     +--------------+
  Pixel Error --> |  PID   | ------------------> | Micro Servo  |
 (Target-Center)  |  Loop  |                     | (Pan/Tilt)   |
                  +--------+                     +--------------+
```

**Tuning Sequence:**
1. **Kp only**: Increase until turret tracks aggressively but shows brief oscillation at stop points
2. **Kd dampening**: Increase to counter stopping oscillations. Excessive Kd feeds noise (30-60 FPS CV latency)
3. **Ki droop elimination**: Add tiny Ki only if camera lags behind steady-speed target. **CRITICAL: integral anti-windup** — clamp accumulator when target leaves servo 180° range, prevents violent oscillation on re-entry
4. **MG90S filter**: LPF alpha ≈ 0.15 (more damping than SG90's 0.2 due to metal gear inertia)

**Power isolation: MANDATORY** — Both servos at stall draw ~1.6A total (2 × 800mA). Running from FC 5V rail WILL brownout the MicoAir H743. DEDICATED 5V/3A UBEC on the 2S payload battery is NOT optional.

## §3. 🟢 CG & WEIGHT DISTRIBUTION COMPUTED

### Static Moment Balance

Using flight controller geometric center as origin (x=0), nose-positive convention:

| Component | Mass (g) | Position x (mm) | Moment (g·mm) |
|-----------|----------|-----------------|--------------|
| Frame + FC + hardware | 48.0 | 0 | 0 |
| Motors (balanced F/B) | 56.0 | 0 | 0 |
| 4S 850mAh battery (top, shifted aft) | 88.0 | -15 | -1320 |
| DroneBridge ESP32 | 6.0 | -5 | -30 |
| ESP32-CAM | 5.0 | +30 | +150 |
| Hawkeye Thumb 4K | 17.0 | +10 | +170 |
| Pump + nozzle (nose) | 23.0 | +40 | +920 |
| Pan servo | 13.4 | +25 | +335 |
| Tilt servo | 13.4 | +25 | +335 |
| Pinch valve | 6.0 | +30 | +180 |
| Reservoir (variable) | 50.0 (100ml full) | x_res | 50·x_res |
| Water (variable) | 50.0 | x_res | 50·x_res |

**Sum of static moments** (excluding reservoir and water):
-1320 - 30 + 150 + 170 + 920 + 335 + 335 + 180 = +740 g·mm

**To balance at origin (∑M = 0):**
740 + (100 × x_res) = 0
x_res = -7.4 mm

**The reservoir must be placed 7.4mm BEHIND the frame geometric center** to balance the nose-heavy pump/servo/camera assembly.

**Practical implications:**
- Medical IV bag: slung below frame, centered just aft of midpoint
- With 50ml water: bag position at -7.4mm relative to FC center
- As water drains (50ml → 0ml), CG shifts forward by ~3.7mm — within acceptable margin for ArduPilot trim compensation
- The battery at -15mm partially counterbalances nose weight — larger 4S 1300mAh (~120g) would shift CG further aft, requiring reservoir to move even further forward

**CG shift during flight:** As water is expended, the CG migrates ~3-4mm forward. This is manageable through:
1. ArduPilot's automatic trim learning (AUTOTUNE)
2. Pre-programmed trim offset proportional to pump activation count
3. Accepting that horizontal CG shift of 3-4mm on a 150mm wheelbase is negligible (<3% of wheelbase)

## §4. 🟢 WIFI BRIDGE DECISION: DroneBridge ESP32

### ELRS WiFi Backpack vs DroneBridge ESP32 — Full Comparison

| Factor | ELRS WiFi Backpack | DroneBridge ESP32 |
|--------|-------------------|-------------------|
| **Architecture** | MAVLink over LoRa RC link → WiFi at TX | Direct ESP32 → WiFi/ESP-NOW |
| **Range** | Extreme (same as RC link, miles) | **Short-Medium** (WiFi ~150m, ESP-NOW LR ~1km) |
| **Drone-side weight** | **~1g** (uses existing RX) | ~6-8g (dedicated ESP32 board) |
| **UARTs required** | 1 (shared with RC) | 2 (1 for RX + 1 for bridge) |
| **Bandwidth** | Low (optimized for RC packets) | **HIGH** (full WiFi bandwidth) |
| **CV video streaming** | ❌ IMPOSSIBLE (RC bandwidth) | ✅ POSSIBLE (WiFi to ground laptop) |
| **WiFi conflict** | None (WiFi only on ground side) | **⚠️ 2.4GHz with ELRS if unshielded** |
| **Setup** | Flash ELRS RX + TX firmware | Web flasher + ArduPilot params |
| **Independence** | Tied to ELRS ecosystem | **Protocol-agnostic** |
| **Security** | ELRS binding | AES-GCM 256-bit encryption |
| **Power draw** | Negligible | ~200mA (ESP32 active) |

### Splash Architecture Decision

**For Splash, DroneBridge ESP32 is the correct choice.** Here's why:

1. **HIGH BANDWIDTH REQUIRED** — Splash's CV pipeline processes video on the ground station (MacBook M3). The DroneBridge ESP32's WiFi bandwidth can stream CV frames at 640×480 for YOLO inference. ELRS WiFi Backpack's LoRa bandwidth cannot.
2. **BENCH DEVELOPMENT** — DroneBridge's web UI enables rapid parameter tuning without reflashing. The independent UART means you can connect Mission Planner for real-time tuning while the RC link stays on ELRS.
3. **ESP-NOW LR for field ops** — 1km range with AES-256 encryption is sufficient for schoolyard/courtyard Senior Assassins ops. DroneBridge operates at low latency (3.4ms vs 33ms CV cycle — 10× headroom).
4. **UART availability** — MicoAir H743 v2 has 6+ UARTs. Using UART4 (TELEM2) for DroneBridge and UART2 (RC) for ELRS is trivial.

**Implementation:**
- Wire DroneBridge ESP32 to FC UART4/TELEM2
- `SERIAL4_PROTOCOL=2` (MAVLink 2)
- `SERIAL4_BAUD=115` (115200)
- ESP-NOW LR mode for outdoor ops
- Ground unit: Second ESP32 + USB/UART to MacBook M3
