## §1. 🛡️ GAP RESOLVED: Conformal Coating Procedure (MG Chemicals 422B)

**Source:** Google AI Mode — Conformal coating electronics drone water protection MG Chemicals 422B

### Complete Application Guide

| Phase | Step | Detail |
|-------|------|--------|
| **Clean** | IPA scrub | 99% isopropyl + antistatic brush on FC/ESC. Remove flux, grease, dirt. 10 min dry. |
| **Mask** | Barometer | Small hole on FC — hot glue or painter's tape |
| **Mask** | USB/SD | Insert dummy plugs |
| **Mask** | Buttons | Tape over boot/bind buttons |
| **Mask** | JST pins | Tape internal mating faces |
| **Coat** | Side 1 | Thin brush layer over all SMD, MCU legs, solder pads. Let 5-8 min tack-free. |
| **Coat** | Side 2 | Flip and repeat. Let 5 min flash-off. |
| **Coat** | 2nd coat | Both sides again — thin layers > one thick. |
| **Verify** | UV check | 422B fluoresces neon blue under UV/blacklight. Touch up dark patches. |
| **Cure** | Room temp | 24-48 hours before power-up. |
| **Cure** | Accelerated | 20 min at 65°C after 10 min room temp flash-off. |
| **Unmask** | Remove tape/plugs | Clean runs with MG 435 thinner if needed. |

### Splash-Specific Notes
- **ESC:** Coat entire PCB + capacitor legs. If using heatshrink, drip 422B into open ends.
- **MicoAir H743:** Pay extra attention to MCU underside (raised legs). Coat every SMD component.
- **Motors:** DO NOT coat. Stock enamel insulation is sufficient. Use bearing oil periodically.
- **Solder-through:** 422B allows soldering directly through the coating — heat vaporizes it instantly. Re-coat afterwards.

## §6. 💧 GAP RESOLVED: Pump Bench Test — Nozzle vs Range Data

**Source:** Google AI Mode — Micro diaphragm pump bench test nozzle water range

### Bench Test Data: 18g Coreless 12V Micro Diaphragm Pump
(Free flow: 0.60 L/min, Max pressure: 2.5 bar / 250 kPa)

| Nozzle | Backpressure | Flow | Velocity | Range | Assessment |
|--------|-------------|------|----------|-------|------------|
| **1.5 mm** | 2.0 bar | 0.22 L/min | Low (atomized) | 0.40-0.55 m | Over-restricted, atomizes |
| **1.8 mm** | 1.4 bar | 0.32 L/min | Best stream | **0.42-0.58 m** | ✅ Sweet spot |
| **2.0 mm** | 0.9 bar | 0.41 L/min | Low pressure | 0.45-0.62 m | Under-restricted |

### Critical Findings
1. **MAX RANGE:** <20g micro pumps CANNOT achieve >2m range — physical limit is ~0.6m bench, ~0.3m in prop wash
2. **Prop wash kills range:** Downdraft shears low-mass streams. 1.5mm atomizes instantly. 2.0mm performs best in wind due to higher mass.
3. **Optimal nozzle:** 1.8mm tapered (12° contraction cone + 1.5× diam land length) — best stream cohesion
4. **Recoil force:** ~0.011 N (1.13g) — negligible for 315g AUW drone
5. **Sweet spot confirmed:** 1.8mm nozzle on 18g pump at 12V

### If >2m range is required
Options for longer range (all add weight):
- **Accumulator impulse** — Pressurize bladder, solenoid burst (higher momentary velocity)
- **Gear pump** — Higher continuous pressure at same weight (~18g)
- **Larger pump** — R385 class (60g, 3-4m range)
- **Pressurized tank** — Pre-charged CO2 or compressed air (regulatory implications)

### Splash Impact
- Engagement range limited to **0.5-2m** with current pump
- For Senior Assassins at close quarters (hallways, courtyards), this is viable
- If longer range is mission-critical, **upgrade pump** is the decision needed

## §7. 🎛️ HOUR 8: ArduPilot Payload Tuning

**Source:** Google AI Mode — ArduPilot parameter tuning payload sub-250g

### Target Parameters (50g payload on 3" micro quad)

| Parameter | Value | Purpose |
|-----------|-------|---------|
| `MOT_THST_EXPO` | 0.60 | Thrust linearization for 3" props |
| `INS_GYRO_FILTER` | 60.0 Hz | Clean micro-frame vibration before PID |
| `ATC_RAT_RLL_FLTD` | 50.0 Hz | Roll rate filter cutoff |
| `ATC_RAT_PIT_FLTD` | 50.0 Hz | Pitch rate filter cutoff |
| `ATC_RAT_RLL_FLTE` | 0.0 Hz | Disable secondary roll filter |
| `ATC_RAT_PIT_FLTE` | 0.0 Hz | Disable secondary pitch filter |
| `PSC_THR_HOVER` | 1 (Learn) | Auto-calculate hover throttle with payload |
| `PSC_ACCZ_P` | = MOT_THST_HOVER | Vertical position P gain scaled to hover |
| `PSC_ACCZ_I` | = 2× PSC_ACCZ_P | Vertical position I gain |

### Tuning Workflow
1. **Apply filter params first** (without payload)
2. **Unladen hover test** — 1 min, check motor temps (must be cool)
3. **Mount payload at CG** — critical for pitch/yaw balance
4. **Hover learning flight** — AltHold mode, 30s hover → MOT_THST_HOVER auto-calculated
5. **Scale PSC_ACCZ** — P = MOT_THST_HOVER learned value; I = 2× P
6. **Autotune** — RCx_OPTION=17, fly in low wind, tune roll then pitch

### Micro Quad Specifics
- Low rotational inertia → micro drones react faster to noise
- Default 20Hz filters are too low for 3" micro — cause oscillation
- 50g payload = 20-25% weight change for sub-250g → significant control impact
- `ATC_GND_EFFECT_EN=1` to prevent ground-effect over-pressurization during takeoff/landing

## §8. 🧪 HOUR 8: Flight Test Plan

**Source:** Google AI Mode — FPV drone flight test plan tethered hover orbit mode

### Phase 1: Pre-Flight Safety
- [ ] Propellers: Cracks, chips, nut tightening
- [ ] Electronics: Secure mounting, conformal coating verified
- [ ] Water system: Pump seals, hose connections, nozzle alignment
- [ ] Battery: Secure mount, CG check
- [ ] Failsafes: RC link loss → Auto-Land; RTL switch bound
- [ ] GPS: Minimum 12 satellites, HDOP < 1.5
- [ ] Wind: <15 km/h, clear visibility

### Phase 2: Tethered Hover
- Anchor 1.5m lightweight cord to drone center, heavy ground weight
- Arm in Stabilize, check motor direction
- Slowly climb to 1m, hover 30s
- Check: Frame vibrations, telemetry, tether pull
- **Pass criteria:** Stable hover, no oscillations, cool motors

### Phase 3: Free Hover
- Remove tether. Take off to 3m altitude.
- Switch to AltHold/GPS Hold. Release sticks — hands-free hover 60s.
- Check: Position drift, altitude hold quality, response to small inputs
- **Pass criteria:** Holds within 2m circle, altitude ±0.5m

### Phase 4: Orbit Validation
- Climb to 5m, position 10m from target center
- Set current location as orbit center (GCS)
- Engage Orbit mode: 5m radius, 2 m/s speed
- Monitor: Radius maintenance, nose pointing at center
- Test: Override to Manual mid-orbit → return to landing zone
- **Pass criteria:** Stable orbit, clean manual override, no GPS drift

### Phase 5: Payload Integration
- Fill reservoir: 25% → Free hover test (slosh evaluation)
- Fill to 100% → Verify lift capability
- 4m altitude → 2s water burst while hovering
- Record: Backward pitch/altitude drop from recoil
- Execute orbit + fire sequence simultaneously
- **Pass criteria:** Stable flight through all water levels, minimal recoil

### Emergency Procedures
| Scenario | Action |
|----------|--------|
| Flyaway | Switch to Manual; if unresponsive, RC kill switch |
| Water leak | Aux switch → cut pump power |
| Battery sag (<3.5V/cell) | Land immediately |
| Loss of control | Physical RTL switch on TX |
| CV target loss | 3s hold-and-scan → loiter → RTL after 15s |
