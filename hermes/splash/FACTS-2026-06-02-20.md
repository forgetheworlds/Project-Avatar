## FACT-048: MOTION COMPENSATOR — IMU GYRO HOMOGRAPHY FOR EGO-MOTION
**Severity: HIGH | Category: CV/Tracking**
MotionCompensator class added to splash/cv/main.py. Compensates for drone ego-motion using ATTITUDE (roll/pitch/yaw) from MAVLink IMU. Computes homography H = K @ R @ K_inv. Stabilizes both frames (warpPerspective) and pixel coordinates (perspectiveTransform). Default camera matrix auto-computed from FOV (70° HFOV, 50° VFOV at 640×480: fx≈541, fy≈550). Optional enable/disable. Without this, drone roll/pitch changes cause turret oscillation even when targets are stationary relative to ground. Integrated into SplashCVPipeline.process_frame() with roll_deg/pitch_deg/yaw_deg parameters.

## FACT-049: LAB COLOR CLASSIFIER — CIELAB SPACE FOR OUTDOOR JERSEY ID
**Severity: MEDIUM | Category: CV/Tracking**
LABColorClassifier added to splash/cv/detector.py. Uses CIELAB (L*a*b*) color space, which is superior to HSV for outdoor color classification because L* (lightness) is decoupled from a*/b* (color). HSV H channel becomes unstable under variable outdoor lighting (shadows, sunlight angle). Pipeline: (1) CLAHE pre-processing on L* channel, (2) BGR→LAB conversion, (3) threshold a*/b* channels. Team A (red): a*>140, b*<140. Team B (blue): a*<130, b*<120. ~2ms overhead after YOLO detection. Set as default classifier (use_lab=True). HSVColorClassifier retained as fallback for indoor/controlled lighting.
**Action:** Test outdoors with actual team jersey colors. Tune a*/b* thresholds if needed.
