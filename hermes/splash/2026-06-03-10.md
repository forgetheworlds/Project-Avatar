## 1. EXECUTIVE SUMMARY

This hour focused on **flight hardware selection, weight budget analysis, power budget, and component compatibility** for the Splash sub-250g water gun drone. The major finding is that the SpeedyBee Master3X frame (87g) is too heavy for a sub-250g build with payload. A weight audit reveals the target build will likely exceed 250g, requiring either lighter components or registration acceptance.

### CRITICAL ISSUE: Weight
At 87g, this frame consumes 35% of the sub-250g budget before any other components. Typical 3.5" freestyle frames weigh 40-60g (e.g., Volador VX3.5 at 70.5g, AOS 3.5 at ~55g, toothpick frames at 26g).

| Parameter | Value |

| Motor size | 1505 (stator Ø15mm × height 5mm) |
| KV | 3800KV |

| Prop | 3.5" triblade |
| Thrust (estimated) | ~150-180g per motor at 100% |
| Dry weight | ~5.5g each |
| Total motor weight | ~22g |

### Assessment
✅ 1505 3800KV on 4S with 3.5" props is within the Oscar Liang recommended range (3500-4000KV for 3.5" freestyle on 4S). However, the skill references 1505 motors while Oscar's table shows 1404/1504/1604/2004 as appropriate sizes for 3.5" 4S. 1505 is slightly larger stator than 1504, which may reduce efficiency slightly but provide more torque for payload.

**Note:** Most sub-250g 3.5" builds use 1404 motors (lighter, ~4.5g each) to save weight. 1505 provides 20% more torque at 20% more mass — worthwhile for the 50g payload.

## 5. BATTERY: 4S 850mAh LiPo

| Parameter | Value |
|-----------|-------|
| Configuration | 4S (14.8V nominal) |
| Capacity | 850mAh |
| Weight | ~95g (typical) |
| Burst C-rating | 75-100C (60-85A burst) |
| Connector | XT30 (standard for this size) |
| Est. flight time (hover) | ~5-7 minutes (without payload) |
| Est. flight time (with payload) | ~3-5 minutes |

### Source Data
The sub-250g guide from FPV Know-It-All confirms 4S 850mAh is the standard battery for 3.5" builds, weighing 100-150g. Real builds report 5-9 minutes flight time depending on weight.

### LiPo vs Li-Ion Tradeoff
| Feature | 4S 850mAh LiPo | 2S 5000mAh Li-Ion (geofrancis) |
|---------|---------------|-------------------------------|
| Weight | ~95g | ~80g |
| Energy | 12.6Wh | 37Wh (3× more) |
| Burst current | 60A+ | 10A |
| Flight time | 3-7 min | 55-65 min |
| Use case | Freestyle | Long range |
| **Splash fit** | ✅ Freestyle + payload | ❌ Too little burst for payload |

**Conclusion:** 4S 850mAh LiPo is correct for Splash. The geofrancis 1-hour build uses Li-Ion for endurance, but Splash needs burst current for the payload.

## 8. ESP32-S3 WIFI BRIDGE: DroneBridge for ESP32

**Source:** ArduPilot docs (→ [[common-esp32-telemetry]]), GitHub DroneBridge/ESP32

| Parameter | Value |
|-----------|-------|
| Weight | <8g |
| Range | 150m+ (standard WiFi), up to 1km (ESP-NOW) |
| Data rate | 250kbit (ESP-NOW), 11Mbit (WiFi) |
| Encryption | AES-GCM 256 bit |
| Protocols | MAVLink, MSP, LTM, transparent |
| Power | From FC UART (3.3V or 5V) |
| GCS support | QGroundControl, Mission Planner, mwptools |

### Architecture for Splash
```
Phone/Tablet → WiFi → ESP32 (DroneBridge) → UART → MicoAir H743 FC (MAVLink)
```

The ESP32 runs DroneBridge firmware, connecting to the FC via UART2 (SERIAL4). The phone connects to the ESP32's WiFi AP for MAVLink telemetry and command upload. QGroundControl auto-discovers the connection.

**Key advantage:** No additional telemetry radio needed — the same ESP32 handles both WiFi bridge and payload servo/pump control.

### ⚠️ CRITICAL FINDING: Weight Over Budget
The total AUW of ~315g exceeds the 250g target by **65g (26%)**.

**Contributing factors:**
1. Frame (SpeedyBee Master3X at 87g) — heaviest single component
2. Battery (4S 850mAh at 95g) — 30% of total weight
3. HawkEye camera (16g) — luxury item for recording, not flight-critical

### Weight Reduction Options

| Option | Savings | Impact |
|--------|---------|--------|
| Replace frame with AOS 3.5 (55g) | ~32g | Maintains durability, saves most |
| Replace frame with toothpick (26g) | ~61g | Fragile, may not support payload |
| Remove Hawkeye, use nano analog cam | ~10g | Loses HD recording |
| Use 3S 550mAh battery (48g) | ~47g | Reduces flight time to ~3 min |
| Use 1404 motors (vs 1505) | ~4g | Less torque for payload |
| Remove GPS | ~3g | No autonomous modes |

**Best path:** Replace frame + use lighter camera to save ~42g, bringing AUW to ~273g — close to 250g. Full compliance requires structural changes.

## 10. POWER BUDGET

### Current Draw Estimates (4S system)

| Component | Current (A) | Notes |
|-----------|------------|-------|
| 4× 1505 motors (hover) | ~8A total | 35% throttle |
| 4× 1505 motors (burst) | ~32A total | 100% throttle |
| MicoAir FC + ELRS RX | ~0.5A | |
| ESP32 (transmitting) | ~0.25A | |
| Hawkeye camera | ~0.3A | |
| Servos (idle/moving) | ~0.2A / 0.8A | |
| Water pump | ~0.35A | |
| **Hover total** | **~9.6A** | Electronics + hover thrust |
| **Burst total** | **~34.2A** | Full throttle + all peripherals |

### Battery Capability
- 4S 850mAh 80C → 68A continuous burst (well within limits)
- At 9.6A hover draw: ~4.5 minutes flight time (80% depth)
- At 34.2A burst: ~1.2 minutes aggressive

### Power Distribution
- 4S battery → FC (with integrated 35A ESC) — powers motors directly
- FC's 12V BEC (2A) → Hawkeye camera, VTX
- FC's 5V BEC (2A) → ESP32, ELRS RX, servo rail
- Pump: switched via MOSFET from 5V BEC or separate 2S pack
- **Separate 2S 300mAh for pump recommended** — keeps pump spikes off FC power rail

## 12. COMPONENT WIRING ARCHITECTURE

### Proposed Splash Wiring
```
4S LiPo
  ├── MicoAir H743 AIO (battery pads)
  │     ├── Motor 1-4 (ESC outputs)
  │     ├── UART1 (TX1/RX1) → ESP32 (MAVLink)
  │     ├── UART3 (TX3/RX3) → GOKU GPS
  │     ├── UART5 (RX6) → ELRS receiver
  │     ├── I2C (SDA/SCL) → External compass (if GPS lacks one)
  │     ├── 5V BEC → ESP32 power, receiver, servo rail
  │     └── 12V BEC → Hawkeye camera, VTX
  │
  ├── [Optional] 2S 300mAh (separate)
  │     └── IRFZ44N MOSFET → Micro water pump
  │         └── ESP32 GPIO (gate control)
  │
  └── SpeedyBee Master3X frame

ESP32 (DroneBridge firmware)
  ├── PWM → Pan servo (SG90)
  ├── PWM → Tilt servo (SG90)
  ├── GPIO → MOSFET gate (pump trigger)
  └── WiFi → Phone/tablet (QGroundControl)
```
