## 1. COMPLETE WIRING DIAGRAM — MicoAir H743-AIO

### 1.1 FC Specifications (from ArduPilot docs)
- **MCU:** STM32H743, 2MB flash, 1MB RAM
- **IMU:** BMI088 + BMI270 (dual redundant)
- **Barometer:** DPS310
- **BEC:** 12V 2A + 5V 2A (built-in)
- **Integrated 4-in-1 ESC:** AM32 35A (channels M1-M4)
- **5 extra PWM outputs:** M5-M9
- **7 UARTs:** UART1 (MAVLink2), UART3 (GPS), UART6 (RCIN), UART7 (ESC Telemetry), UART8 (User)
- **MicroSD slot, I2C, SWD**

### 1.2 PWM Output Groups (CRITICAL for servo control)
| Group | Channels | Notes |
|-------|----------|-------|
| Group 1 | M1, M2, M3, M4 | Internally tied to 4-in-1 ESC. DShot300 |
| Group 2 | M5, M6 | Independent protocol selection — **USE FOR PAN/TILT SERVOS** |
| Group 3 | M7, M8, M9 | M9 labeled "LED" on board. **USE M7 FOR PUMP TRIGGER** |

All groups on same output protocol within group. Groups 2 and 3 can be set to 50Hz PWM for analog servos.

### 1.3 UART Assignment
| UART | SERIAL# | Peripheral | Notes |
|------|---------|------------|-------|
| UART1 | SERIAL1 | ESP32 WiFi Bridge | MAVLink2, 115200 baud |
| UART3 | SERIAL3 | GPS (GOKU GM10) | GPS protocol, 115200 baud |
| UART6 | SERIAL5 | RC Receiver (ELRS) | RCIN protocol, CRSF |
| UART7 | SERIAL6 | ESC Telemetry | RX only, bi-directional DShot |
| UART8 | SERIAL7 | User / Spare | Available for future expansion |
| I²C | — | GPS Compass | SCL + SDA |

## 2. SERVO & PAYLOAD CONTROL IN ARDUPILOT

### 2.1 ⭐ CRITICAL FINDING: ArduPilot Has Built-in Sprayer Function
ArduPilot includes a **Sprayer Pump** output function (ID 22) and **Sprayer Mixer** (ID 23) for Copter! This was designed for agricultural drones but is directly applicable to Splash's water gun.

**SERVO Functions for Splash:**
| Function | ID | Use |
|----------|----|-----|
| RCPassThru | 1 | Raw RC passthrough for manual trigger |
| Mount Yaw | 6 | Pan servo, can use gimbal stabilization |
| Mount Pitch | 7 | Tilt servo, can use gimbal stabilization |
| Sprayer Pump | 22 | **Water gun pump trigger!** Built-in ArduPilot support |
| Disabled | 0 | Manual control via MAVLink `DO_SET_SERVO` |
| RCPassThru1..16 | 51-66 | Map specific RC channel to output |
| LUA Script | 94-109 | Programmatic control from onboard Lua scripts |

### 2.2 Recommended Splash Servo Configuration
```
SERVO5_FUNCTION = 6    # Mount Yaw (Pan) - on M5
SERVO6_FUNCTION = 7    # Mount Pitch (Tilt) - on M6
SERVO7_FUNCTION = 22   # Sprayer Pump - on M7
```

**Alternative for manual test phase:**
```
SERVO5_FUNCTION = 1    # RCPassThru - RC channel 5 → Pan
SERVO6_FUNCTION = 1    # RCPassThru - RC channel 6 → Tilt
SERVO7_FUNCTION = 1    # RCPassThru - RC channel 7 → Fire
```

### 2.3 Servo Power Notes
- M5/M6/M7 on Group 2/3 can run at standard 50Hz PWM for analog servos
- MicoAir H743-AIO has 5V 2A BEC — sufficient for 2× micro servos (SG90: 220mA stall each)
- **Do NOT power servos from FC servo rail alone if using digital/MG servos.** External 5V BEC recommended for payloads >1A.
- For pump: 12V BEC (2A) from FC can power a small pump, but use MOSFET (IRFZ44N) switched by M7 PWM signal

## 3. FAILSAFE CONFIGURATION

### 3.1 Battery Failsafe (Two-Layer)
From ArduPilot docs — configure in Mission Planner:
```
BATT_MONITOR      = 4       # Analog Voltage & Current
BATT_VOLT_PIN     = 10      # MicoAir default
BATT_CURR_PIN     = 11      # MicoAir default
BATT_VOLT_MULT    = 21.2    # MicoAir default calibration
BATT_AMP_PERVLT   = 14.14   # MicoAir default calibration

# Low battery (first warning) → RTL
BATT_FS_LOW_ACT   = 2       # RTL (Return to Launch)
BATT_LOW_VOLT     = 14.0    # 3.5V/cell for 4S (14.0V total)
BATT_LOW_MAH      = 680     # 80% of 850mAh

# Critical battery (emergency) → Land Immediately
BATT_FS_CRT_ACT   = 1       # Land
BATT_CRT_VOLT     = 13.2    # 3.3V/cell for 4S (13.2V total)
BATT_CRT_MAH      = 765     # 90% of 850mAh
```

### 3.2 Radio/Telemetry Failsafe
```
FS_THR_ENABLE     = 1       # Enable radio failsafe → RTL
FS_THR_VALUE      = 950     # Below this PWM = failsafe
FS_GCS_ENABLE     = 1       # GCS failsafe → RTL
```

### 3.3 Geofence
```
FENCE_ENABLE      = 1       # Enable geofence
FENCE_TYPE        = 3       # Altitude + Circle
FENCE_ACTION      = 1       # RTL on breach
FENCE_RADIUS      = 100     # 100m radius
FENCE_ALT_MAX     = 30      # 30m max altitude
```

### 3.4 Splash-Specific Safety Requirements
- **Water kill switch:** Physical switch on drone or RC channel that immediately disables pump (prevents accidental firing)
- **Arming check:** Add check that pump is OFF before allowing arm
- **Lost-link behavior:** RTL with pump disabled (don't spray while returning home)
- **Low-battery abort:** At BATT_CRT_VOLT, Land immediately even if mid-engagement

## 4. CENTER OF GRAVITY CALCULATION

### 4.1 CG Formula
```
X_cg = Σ(m_i × x_i) / M_total
```
Where:
- m_i = mass of component i
- x_i = distance from datum (front tip of frame)
- M_total = total mass

### 4.2 Splash Weight Estimate (Measured from Datum = Front of Frame)
Assuming 140mm frame length, CG target at 70mm from datum:

| Component | Mass (g) | Position from Datum (mm) | Moment (g·mm) |
|-----------|----------|-------------------------|---------------|
| Frame (Master3X) + Hardware | 80 | 70 | 5,600 |
| MicoAir H743-AIO Stack | 18 | 70 | 1,260 |
| Motors (4× 1505) | 54 (13.5×4) | 70 (at arms) | 3,780 |
| Props (4×) | 12 | 70 | 840 |
| Hawkeye Thumb 4K | 17 | 20 (front) | 340 |
| GOKU GPS + Mount | 5 | 130 (rear) | 650 |
| ESP32-S3 | 5 | 40 (mid-front) | 200 |
| ELRS RX | 2 | 80 | 160 |
| Water Gun Payload | 50 | 25 (front-bottom) | 1,250 |
| 4S 850mAh LiPo | 95 | x_batt (variable) | 95 × x_batt |
| Wiring, HW | 10 | 70 | 700 |
| **Subtotal (no battery)** | **253g** | — | **14,780** |

Wait — 253g + 95g battery = 348g. That's OVER 250g. Problem.

### 4.3 CRITICAL: Weight Budget Analysis
The build as specified exceeds 250g. Options:
1. **Lighter frame:** SpeedyBee Master3X is 80g (heavy). Geofrancis 6mm carbon tube frame = ~17g. Saves 63g → total ~285g (still over)
2. **Lighter battery:** 4S 450mAh (55g) instead of 850mAh → saves 40g → total ~308g (still over)
3. **3S instead of 4S:** 3S 650mAh (~55g). But 1505 3800KV on 3S gives ~30% less thrust
4. **Remove Hawkeye Thumb (17g):** Use ESP32-CAM (2g) as CV camera. Hawkeye only for recording
5. **Realistic approach:** Target under 250g WITHOUT battery (many jurisdictions measure AUW including battery). OR accept 260-280g as within tolerance

**Revised lightweight build target:**
| Component | Mass (g) |
|-----------|----------|
| Geofrancis tube frame | 17 |
| MicoAir H743-AIO | 18 |
| 1505 3800KV × 4 | 54 |
| Lightweight props × 4 | 10 |
| GOKU GPS | 5 |
| ESP32-CAM (CV only) | 5 |
| ELRS RX (EP2) | 1 |
| Water gun payload | 50 |
| Wiring | 8 |
| **Subtotal (no battery)** | **168g** |
| 4S 650mAh LiPo | 75g |
| **TOTAL** | **243g** ✅ |

**Motor thrust check:** 1505 3800KV on 4S with 3.5" props: estimated 350-400g thrust each at full throttle = 1,400-1,600g total. At 243g AUW, thrust-to-weight = 5.7-6.6:1 — excellent.

## 5. WATERPROOFING & ENVIRONMENTAL PROTECTION

### 5.1 Conformal Coating Procedure (Oscar Liang, 2023/updated 2026)
- **Product:** MG Chemicals Silicone Conformal Coating 422C (~$20, 55ml bottle)
- **UV version recommended** — fluoresces under UV light to verify coverage
- **Application:** Brush-on (NOT spray). Apply like nail polish
- **DO NOT COAT:** Barometer (DPS310), boot button, USB port, bind button, camera image sensor
- **Drying time:** 30 min minimum, overnight recommended
- **Removal:** Isopropyl alcohol + brush, or burn through with soldering iron

### 5.2 Water-Specific Protections for Splash
- **FC + ESC:** Full conformal coat both sides of PCB (already partially done on MicoAir)
- **Connectors:** Plug in all connectors BEFORE coating to protect contact surfaces
- **GPS:** Coat except ceramic antenna patch (can degrade signal)
- **ESP32:** Coat except antenna area
- **Camera:** Do NOT coat lens or image sensor. Coat PCB back only
- **Barometer:** Mask with tape before coating — DPS310 must breathe
- **Motors:** Generally waterproof (outrunner BLDC), but conformal coat ESC connections

### 5.3 Crash-in-Water Recovery
1. Disconnect battery IMMEDIATELY (before lifting from water)
2. Rinse with distilled water to remove minerals
3. Brush with isopropyl alcohol (not motors)
4. Dry with fan for 24+ hours (NOT rice)
5. Check all connections before re-powering

### 5.4 Splash-Specific Hazard: Self-Spray
The water gun payload is MOUNTED ON the drone. Spray could:
- Hit own propellers (water ingestion → motor damage)
- Spray back onto camera lens (CV failure)
- Drip onto electronics below

**Mitigations:**
- Nozzle angled downward at 30-45° (already in design for ballistic trajectory)
- Shield/splash guard between nozzle and drone body
- Conformal coat is NON-NEGOTIABLE for Splash
- Test spray pattern on ground before flight

## 6. FLIGHT TEST PLAN

### 6.1 Simulation Phase (BEFORE Hardware)
1. **ArduPilot SITL:** Simulate autonomous mission logic on desktop
   ```bash
   sim_vehicle.py -v Copter --console --map
   ```
2. Test waypoint navigation, orbit mode, RTL behavior
3. Test MAVLink command interface for `DO_SET_SERVO`, mode changes
4. Simulate battery failsafe scenarios

### 6.2 Phase 1: Tethered Hover (Ground Testing)
**Goal:** Verify basic flight stability, no payload
- **Setup:** Drone tethered to 2m string anchored to ground
- **No payload attached**
- Verify motor directions, arming, hover stability
- Check GPS lock quality, compass calibration
- Monitor vibration levels in logs
- Duration: 2-3 battery cycles

### 6.3 Phase 2: Free Hover (No Payload)
**Goal:** Verify stable flight without tether
- Stabilize mode only
- AltHold mode test
- Loiter/GPS position hold test
- RTL test from 30m distance
- Duration: 5 battery cycles

### 6.4 Phase 3: Payload Integration — Static
**Goal:** Verify CG with water gun payload (NO WATER)
- Mount full payload (pump, servo, reservoir, nozzle) — DRY
- Verify CG at center (adjust battery position)
- Tethered hover with payload
- Check flight time impact
- Duration: 3 battery cycles

### 6.5 Phase 4: Payload Integration — Wet Test (Ground)
**Goal:** Test water gun mechanism on ground
- Fill reservoir with water
- Test pump trigger via RC channel / MAVLink
- Measure stream distance, spray pattern
- Verify no water ingress to electronics
- Test servo pan/tilt range
- Duration: Ground testing only, multiple reservoir fills

### 6.6 Phase 5: Orbit Mode Test
**Goal:** Verify autonomous orbit capability
- Program orbit waypoint at 3m altitude, 5m radius
- Test with dry payload
- Verify stable orbit, camera pointing
- Test mode transitions (Orbit → Stabilize → RTL)
- Duration: 3 battery cycles

### 6.7 Phase 6: Tracking Test (Manual)
**Goal:** Verify CV tracking + servo aiming
- ESP32/MacBook CV pipeline running
- Drone in Loiter at 2-3m altitude
- Target person walks in front of drone
- Verify servo tracks target (no firing)
- Measure tracking latency, accuracy
- Duration: Multiple ground tests

### 6.8 Phase 7: Live Fire Test
**Goal:** Full system integration — track AND fire
- Tethered or very low (1m) hover
- Target 3m away
- Fire on command via RC/MAVLink
- Verify stream accuracy
- Post-flight water inspection
- **CRITICAL:** Have fire extinguisher / towel ready (water + electronics)

### 6.9 Phase 8: Autonomous Engagement
- Protection mode: Orbit → Detect person → Track → Fire → Return to orbit
- Auto-track mode: Navigate to area → Identify target → Track → Fire on command
- Battery failsafe during engagement
- Lost-link behavior during engagement

## 8. FAILURE MODES & CONTINGENCIES

### 8.1 Splash-Specific Failure Modes
| Failure | Probability | Impact | Mitigation |
|---------|------------|--------|------------|
| Water ingress shorts electronics | HIGH | Drone crash | Conformal coating + splash guard |
| Pump stall/blockage | MEDIUM | No water output | Current sensing on pump circuit |
| Servo jam from water residue | MEDIUM | Cannot aim | MG90S metal gear + conformal coat servo PCB |
| Camera lens fogged by spray | HIGH | CV failure | Lens hood + hydrophobic coating |
| CG shifts as water empties | LOW | Trim change during flight | Small reservoir (15ml = 15g shift, ~6% of AUW) |
| Pump inrush browns out FC | MEDIUM | FC reset mid-flight | 1000µF capacitor on pump power rail |
| Target loss during engagement | HIGH | Wasted battery | Timeout (5s) → return to orbit/search pattern |
| Propeller strikes spray stream | MEDIUM | Motor damage | Nozzle angle optimization |
| Battery sag under pump+motors | MEDIUM | Premature low-battery RTL | Conservative BATT_LOW_VOLT threshold |

### 8.2 Weather Constraints
| Condition | Limit | Reason |
|-----------|-------|--------|
| Wind | <15 km/h (4 m/s) | Sub-250g drone, wind affects spray trajectory |
| Rain | NO FLY | Water damage risk even with coating |
| Lighting | Daylight only | CV requires adequate light |
| Temperature | 5-35°C | Battery performance, water doesn't freeze |
| Humidity | Any | Conformal coat handles this |

## 11. KEY FACTS FOR HOLOGRAPHIC MEMORY

1. **ArduPilot has a built-in Sprayer Pump servo function (ID 22)** — this is directly usable for water gun trigger, no custom code needed.
2. **MicoAir H743-AIO has 5 extra PWM outputs (M5-M9)** on top of the integrated 4-in-1 ESC, sufficient for pan servo + tilt servo + pump MOSFET.
3. **The weight budget is TIGHT:** The initial spec (Master3X frame + 850mAh 4S) exceeds 250g. A lightweight tube frame + 650mAh battery brings it to 243g. Every gram counts.
4. **ArduPilot's two-layer battery failsafe** (RTL at 3.5V/cell, Land at 3.3V/cell) provides safe autonomous abort during engagements.
5. **Conformal coating is NON-NEGOTIABLE** for Splash — the drone carries its own water hazard. MG Chemicals 422C silicone coating is the gold standard.
6. **CG balancing uses the battery as the primary tuning mass** — formula X_cg = Σ(m_i × x_i) / M_total. For 243g build, battery should sit ~78mm back from front datum.
7. **Flight test must follow phased approach:** SITL → tethered → free hover → dry payload → wet ground test → orbit → tracking → live fire. Skipping phases = guaranteed crash.
