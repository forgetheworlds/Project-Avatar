## §2. 🟢 Coreless Gear Pump Option (12-15g) — Detailed Assessment

**Source:** Google AI Mode — Micro coreless gear pump 12-15g drone water payload

### Viability Assessment
A 12V micro coreless gear pump at 12-15g is **technically feasible** but requires DIY assembly:

| Component | Weight | Source |
|-----------|--------|--------|
| 12mm × 15mm coreless motor | 7-10g | AliExpress / NFPSHOP |
| PEEK/PPS gear housing + gears | 4-6g | Custom 3D-printed (SLA) |
| **Total pump** | **12-15g** | — |

**Performance estimates:**
- Flow rate: 400-600 mL/min at 12V (20,000-30,000 RPM)
- Pressure: ~1-2 bar (significantly lower than S18 diaphragm)
- Max range through 1.8mm nozzle: ~1-1.5m (estimated, unverified)
- Self-priming: Weak — requires gravity-fed placement (tank above pump)

### Tradeoff Decision

| Criteria | S18 BLDC (35-40g) | Coreless Gear (12-15g) |
|----------|-------------------|----------------------|
| Range | **2-4m** ✅ | 1-1.5m ⚠️ |
| Weight penalty | 35-40g | **12-15g** ✅ |
| Self-priming | **Yes** ✅ | Weak (gravity feed) |
| COTS availability | **Yes** ✅ | DIY only |
| Pressure consistency | **High** ✅ | Low-Medium |
| PWM control | **Native** ✅ | Via motor ESC |

**Recommendation:** The S18 BLDC (35-40g) remains the best choice for v1 due to superior range (2-4m), self-priming, and COTS availability. The 20-27g weight penalty over a coreless gear pump is worth the mission-critical range advantage. For v2 weight reduction, investigate coreless gear pump if 1-1.5m range is acceptable.

## §3. 🟢 DroneBridge ESP32 — Implementation Readiness

**Source:** Google AI Mode — DroneBridge ESP32 firmware flashing installation ESP32-S3 MAVLink

### Key Findings
- **Latest version:** DroneBridge for ESP32 v2.x (stable, released 2025-2026)
- **ESP32-S3 support:** ✅ Native support, including official HW variant
- **Flashing method:** Chrome WebUSB tool — no toolchain needed
- **Range:** 150-200m WiFi, 1km+ ESP-NOW LR (with IPEX antenna)
- **Latency:** 2-8ms (ESP-NOW), 10-20ms (WiFi)

### Wiring to MicoAir H743

| ESP32-S3 | MicoAir H743 | Notes |
|----------|-------------|-------|
| 5V | 5V rail (from external BEC) | NOT FC 5V (insufficient current) |
| GND | GND | Common ground |
| TX (GPIO18) | FC RX4 (UART4) | Cross-over! |
| RX (GPIO17) | FC TX4 (UART4) | Cross-over! |

### FC Configuration
```
SERIAL4_PROTOCOL = 2    (MAVLink 2)
SERIAL4_BAUD    = 57    (57600) or 921 (921600)
```

### Steps
1. Flash via DroneBridge Online Flasher (Chrome WebUSB)
2. Select: ESP32-S3 → Standard (Air Unit)
3. Wire per table above
4. Connect to WiFi SSID: `DroneBridge for ESP32`, password: `dronebridge`
5. Open http://192.168.2.1 — configure UART settings to match FC
6. QGC auto-discovers MAVLink stream via UDP

### Implementation Blockers
- **None.** DroneBridge is production-ready. Order ESP32-S3 with IPEX connector from Waveshare/AliExpress.
- **Unresolved:** Confirm whether to use WiFi AP mode (150m, sufficient for <100m Splash ops) or ESP-NOW LR (1km, extra setup). Recommendation: Start with WiFi AP for simplicity.
