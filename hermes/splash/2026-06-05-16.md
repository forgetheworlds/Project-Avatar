## §1. 🟢 VERIFIED: Full MicoAir H743 AIO Wiring Diagram

**Source:** Google AI Mode (18 sources, ArduPilot docs)

Confirmed port mapping for Splash:

```
+-----------------------------------------------------------------------+
|                         MicoAir H743 AIO                              |
|                                                                       |
|  [VIN Pad]  <--------- Camera Video Out (Hawkeye Thumb)              |
|  [VOUT Pad] ---------> Analog VTX Video In                           |
|                                                                       |
|  [TX1] --------------> ESP32 RX (MAVLink Bridge / DroneBridge)       |
|  [RX1] <-------------- ESP32 TX (MAVLink Bridge)                     |
|                                                                       |
|  [TX3] --------------> GPS RX (GOKU GM10 Nano V3)                    |
|  [RX3] <-------------- GPS TX (GOKU GM10 Nano V3)                    |
|  [SCL] --------------> Compass SCL (I2C) — REQUIRED (v2 has no int.) |
|  [SDA] --------------> Compass SDA (I2C)                              |
|                                                                       |
|  [M5]  --------------> Servo Pump PWM Signal Line (via ext. BEC)     |
|                                                                       |
|  [VBAT / GND Pads] <-- LiPo Battery Input (4S = 14.8V nominal)       |
+-----------------------------------------------------------------------+
```

**Critical notes:**
- MicoAir H743 AIO v2 (45A, active) has **NO built-in compass** — external compass from GPS module required via I2C2 (PB9=SCL, PB8=SDA)
- Servo pump MUST use external 5V/3A BEC — never power from FC logic rail (brownout risk)
- M5 pad is the servo PWM output (SERVO5_FUNCTION)
- ESP32-S3 DroneBridge is the recommended WiFi bridge (3.4ms latency, 10x headroom over 30fps CV at 33ms)

## §3. 🟢 NEW: Structured Flight Test Plan

**Source:** Google AI Mode (12 sources, FAA best practices)

### Phase 1: Tethered Hover (Validation)
- **Tether:** Anchor drone with high-strength non-elastic cord
- **Imbalance check:** Slow motor spin-up on ground
- **Takeoff:** Manual to 1-1.5m altitude
- **Controls:** Micro-inputs on all axes
- **Telemetry:** Monitor current draw & vibration spikes
- **Duration:** Until stable hover confirmed

### Phase 2: Free Hover (Untethered)
- **Zone:** 10m safety perimeter
- **GPS lock:** DOP < 1.5
- **Stability:** 3-min hover at 3-5m without intervention
- **Drift:** Measure against ground reference
- **Wind rejection:** Intentional stick inputs

### Phase 3: Orbit & Track (Dynamic)
- **Orbit:** POI at center, radius 5-15m, 2-5 m/s
- **Nose:** Inward-facing throughout orbit
- **Speed escalation:** 2 m/s → max cruising
- **Track:** Lock CV onto moving ground target
- **Error:** Monitor cross-track deviation

### Phase 4: Autonomous Operations (Full Mission)
- **Waypoint:** Upload closed-loop multi-point mission
- **Auto-takeoff:** Via GCS
- **Geofence:** Fly toward boundary to verify braking
- **Failsafe:** Simulate lost link → verify RTL
- **Protection mode:** Full end-to-end: orbit → detect → engage → return

## §4. 🟢 NEW: Failure Mode and Effects Analysis (FMEA)

| Failure Mode | Cause | Impact | Mitigation |
|---|---|---|---|
| **Telemetry Loss** | ESP32 saturation/shielding | Complete GCS disconnection | `FS_GCS_ENABLE=1` → auto RTL on 5s timeout |
| **Logic Bus Brownout** | Servo pump peak load on FC rail | FC resets mid-air → crash | External isolated BEC + 470µF low-ESR capacitor across power leads |
| **Compass EKF Variance** | High current distorts magnetometer | Toilet-bowling / erratic nav | Mount GPS/compass on elevated mast ≥5cm from battery wires. Run MagFit at 50% throttle |
| **Video Blackout** | VTX thermal shutdown / broken signal | Loss of situational awareness | RC failsafe (`FS_THR_ENABLE=1`) + physical RTL switch |

### Water Payload-Specific Failure Modes

| Failure Mode | Cause | Mitigation |
|---|---|---|
| **Short circuit/corrosion** | Water on live traces | Silicone conformal coating + ePTFE vented enclosure |
| **Barometer malfunction** | Coating blocks sensor port | Precise masking during coating |
| **Pump burnout** | Nozzle blockage / jammed impeller | Current-limiting eFuse + inline 50-100 mesh filter + pressure relief valve |
| **Pump seal failure** | Running dry | Optical fluid sensor auto-cutoff |
| **Servo gear stripping** | Impact / mechanical jam | Spring-loaded servo saver |
| **Servo corrosion** | Water ingress | IP67-rated servo + marine-grade hydrophobic grease on output shaft |

## §5. 🟢 VERIFIED: 1505 3800KV Thrust Data & Prop Matching

**Source:** Google AI Mode (24 sources incl. Oscar Liang)

### Technical Specs
- Stator: 15mm × 5mm
- KV: 3800 RPM/V
- Voltage: 3S-4S (11.1V-16.8V)
- Weight: 13-16g each
- Max current: ~18A continuous / 290W peak
- Shaft: 1.5mm (micro T-mount)

### Estimated 4S Thrust Data

| Throttle | Current | Thrust | Power | Efficiency |
|----------|---------|--------|-------|------------|
| 25% | 1.2A | 95g | 20W | 4.75 g/W |
| 50% | 4.5A | 260g | 75W | 3.46 g/W |
| 75% | 11.2A | 480g | 188W | 2.55 g/W |
| 100% | 17.5A | **640g** | 294W | 2.17 g/W |

### Propeller Recommendations
- **3" tri-blades** (HQProp T3x3x3, Gemfan 3016/3020): Best for sub-250g. Fastest response, cool motor temps.
- **3.5" tri-blades** (EMAX Avan 3.5x2.8x3, HQProp T3.5x2.5x3): Higher thrust but power-hungry. **Apply 90% motor output limit** for thermal safety.

### Sub-250g Battery Strategy
Research suggests **4S 550-750mAh LiPo** (~65-85g) over 850mAh for sub-250g. The 850mAh adds dead weight for freestyle. Total 4-motor thrust at 50% throttle: ~1040g — gives ~4:1 TWR with ~260g AUW. At 100%: 2560g total — 10:1 TWR.

## §6. 🔴 CRITICAL: SpeedyBee Master3X Frame Weight Reality

**Source:** Google AI Mode (18 sources, manufacturer specs)

**Frame weight breakdown:**
- Bare frame: 87g ± 2g
- Fully assembled (with CNC Al head + TPU): **~145g**
- Carbon: 4mm arms, 2mm plates
- Stack height: 11mm (very tight — AIO only)
- Wheelbase: 171mm

**Sub-250g verdict:** A standard build with 1507 motors + 850mAh battery = ~335g. To reach sub-250g: must use **1404 motors + 450-550mAh battery** = ~245g, but this is **underpowered for payload**. The Google AI verdict states: *"The Master3X is fundamentally overbuilt for sub-250g. If your primary goal is lightweight under 250g, a dedicated ultralight carbon frame is preferred."*

**Existing facts confirm:** Frame swap to custom tube frame (17g, geofrancis-style) or AOS 3.5 (~50g) is necessary. See fact F-2026-05-28-003.

## §7. 🟢 NEW: Water Damage & Pump Protection Guide

### Electronics Protection
1. **Conformal coating:** Silicone-based (SR) or fluoropolymer — apply to FC, ESC, ESP32
2. **Mask:** Barometer, USB ports, connectors, buttons BEFORE coating
3. **Potting:** Two-part epoxy for ESCs mounted on arms
4. **Vents:** ePTFE membrane vent in 3D-printed enclosure — blocks liquid, passes air

### Pump Stall Prevention
1. **eFuse/current limit:** Program current threshold — cut on spike indicating stall
2. **Inline filter:** 50-100 mesh between reservoir and pump inlet
3. **Pressure relief valve:** Mechanical bypass loop — routes back to tank on clog
4. **Dry-run sensor:** Optical fluid sensor — shut down pump on empty tank

### Servo Jam Prevention
1. **IP67 servos:** O-ring sealed, dual ball-bearing shaft
2. **Servo saver:** Spring-loaded horn mechanism to absorb shocks
3. **Marine grease:** Dielectric silicone grease on output shaft
4. **Stall telemetry:** Monitor PWM feedback — if target angle not reached, return to neutral
